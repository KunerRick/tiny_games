# docs/assets —— 本地配图目录（不入库）

这个目录放**文档配图与试玩截图**，全部在 `.gitignore` 里（只放行本文件）。

原因：一轮 UI 试玩 20+ 张、几 MB，对读代码的人没有价值，历史里已经堆了十几 MB。

## 约定

- 试玩截图统一放 `docs/assets/<YYYY-MM-DD>-<game>-round<N>/`；
- 设计文档配图放 `docs/assets/<game>/`；
- 报告和设计文档里**照常写相对链接**（`../assets/…png`）——它是本机查阅指针，
  在远端仓库 / PR 里点不开是**预期**的，不要为了「链接能点」把图提交进去；
- 需要把图给别人看时单独贴（PR 评论、聊天），不要提交；
- 提交范围只有：报告 `.md` + 台账 + 代码 / 配置。

完整规则见 [`../tech/playtest-cycle.md`](../tech/playtest-cycle.md) §7.5。
