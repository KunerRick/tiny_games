# 《秘银远征》美术方向：向 WoW 致敬的暗色奇幻 UI（2026-11-18）

> 触发：第 25 轮试玩 UI 拍。玩家反馈「整体风格希望致敬 WoW，包括配色；营地布局和配色有点奇怪」。
> 本文是**实现规范**，代码令牌在 [`MithrilTheme.ts`](../../assets/games/game_mithril/scripts/MithrilTheme.ts)；
> 第 25 轮报告见 [`2026-11-18-playtest-round25-mithril-ui-camp.md`](../plans/2026-11-18-playtest-round25-mithril-ui-camp.md)。

## 1. 目标与边界

**要的感觉**：暗夜里的石墙房间、深色木梁、黄铜包角、羊皮纸文字、宝石色点缀。
**不要的感觉**：深蓝灰 SaaS 仪表盘、Tailwind 霓虹色、彩虹按钮、无边的空凹槽。

三条硬边界：

1. **零位图**：所有框架 / 图标 / 装饰仍由 `Graphics` 程序化绘制，不引入 WoW 素材；
2. **金色只做结构**：边框、分隔、选中态、主操作；**不给大块正文铺金**，否则整屏发光、失去层次；
3. **玩法身份色独立**：品质 / 职业 / 设施色是「内容语义」，不随主题令牌漂移（见 §3）。

**使用纪律**

- 主操作按钮：金底 + `ink` 文字 + `goldPressed` 按下；
- 次级按钮：`stoneLight` + `parchment` + `stonePressed`；
- 购买 / 领取：`emerald` + `parchment` + `emeraldPressed`；
- 禁用：`stoneDark` + `parchmentMuted`；
- 危险：`danger` 仅用于「放弃 / 销毁」；不要拿红色做主按钮。

## 3. 身份色（内容语义）

### 3.1 品质（WoW 稀有度色相，暗底略提亮）

| 品质 | 名称 | 色 |
|---|---|---|
| common | 普通 | `#9D9D9D` |
| uncommon | 优秀 | `#3FC24E` |
| rare | 稀有 | `#2A7FDE` |
| epic | 史诗 | `#A335EE` |
| legendary | 传说 | `#FF8000` |
| mythic | 秘境 | `#E03A3A` |

定义在 `MithrilConfig.QUALITIES`，是**唯一源**；UI 一律经 `QUALITY_BY_ID` 取色，
不要在主题模块另存镜像表（第 25 轮删掉了旧的 `MITH_QUALITY`，镜像表会漂移）。

### 3.2 设施 / 职业

- 设施：铁匠 `#D9A441` · 附魔 `#9F6FD9` · 训练 `#4F9BD9` · 厨房 `#5FB56A` · 军需 `#D46A5E`
- 职业：战士 `#C79C6E` · 法师 `#69CCF0` · 游侠 `#A9D473` · 牧师 `#F2E6C9`

设施色只用于**图形与未选页签**；选中页签一律金底 + 墨字，防止五个高饱和色打架。

天赋 12 系的图标色（`TREE_GLYPH`）保留较高辨识度的色相，只用于**图形**，不参与文字 / 按钮 / 框架；这是「语义色」而非主题色。

## 4. 结构规范

### 4.1 营地面板（`drawCampFrame`）

- 尺寸 680 × 1180，圆角 26；
- 页头木带高 124：木底 + 7 道暗纹 + 顶部受光 + 下沿双金线；木带下半用石底盖平，形成「嵌进石框」；
- 外框双线：外 3px `goldDim`，内 1px `gold` 70α，内缩 9px；
- 四角铆钉：半径 5 的菱形，`goldBright` 190α，内缩 22px；
- 底部一条很暗的金线交代厚度。

### 4.2 页头

- 左起：菱形装饰（-312, 534）→ 标题「营地」38px `goldBright`（中心偏左 x=-142，字距 6）→ 返回按钮（276, 534，112×48）；
- 第二行：菱形（-312, 492）+ 货币行 16px `parchmentDim`，左对齐；
- 页头与内容之间：`drawGoldDivider` 水平分隔（中心大菱形 + 两端小菱形）。

### 4.3 页签与设施说明

- 5 个页签：120×46，x = -260 / -130 / 0 / 130 / 260，y = 430；
- 未选：`stoneLight` + `parchmentDim` + `goldLine` 描边 + 设施色图形；
- 选中：`gold` + `ink` + 图形/下划线换 `ink`；
- 设施说明块：徽记 27 半径（金色）→ 名称 / 等级 → 当前效果 → 下一级效果，统一左对齐。

### 4.4 内容凹板（`drawInsetBoard`）

- 656 宽，顶 312 / 底 -310，圆角 16；
- `stoneDark` 236α 底 + 顶部 5 道内阴影 + `goldLine` 1.5px 边 + 四角短金括线；
- 内容节点整体下移 36px，保证标题行（y=336）落在凹板内 12px 处；
- **所有列表 / 空态都必须落在这块凹板里**，不允许直接铺在面板石底上。

### 4.5 按钮

- 主操作：360×54（营地升级）/ 200×50（重铸 / 分解）/ 240×52（附魔）等，圆角 12–14；
- `addButtonSheen` 给所有按钮加顶部受光 + 底部阴影（sibling 0，不影响 `setColor`）；
- 文字：金底用 `ink`；石底用 `parchment`；祖母绿底用 `parchment`；
- 禁用按钮直接把门槛写进文案（「需铁匠铺 Lv1」），不要只变灰。

### 4.6 空态（`_emptyState`）

新档首访不能是一整块空凹槽。统一结构：

- 大图形：设施 / 部位 glyph，半径 54，`goldDim`，填充 14α；
- 标题：20px `parchmentDim` 粗体；
- 说明：15px `parchmentMuted`，最多两行，lineHeight 22；
- 下方保留禁用态操作按钮与一句获取提示。

已覆盖：铁匠铺（无装备）、附魔台（无装备）、厨房（未建造）、军需官（未建造 / 悬赏为空）、训练场（方案槽未解锁）。

## 6. 验收清单

- [ ] 营地五个设施页在 Lv0 与高等级两种存档下都无重叠、无「整块空凹槽」；
- [ ] 金底上的文字一律 `ink`，石底 / 绿底文字可读；
- [ ] 页签选中态同时有「金底 + 墨字 + 下划线」，不只靠颜色；
- [ ] 设施色只出现在图形 / 未选页签，不出现在主按钮；
- [ ] 野外图、弹窗、装备、成长、选职业与营地同一套令牌，无旧 Tailwind 蓝紫；
- [ ] 所有面板仍在 720×1280 设计分辨率内，返回键不被遮罩吞掉；
- [ ] 改 `.ts` 后 `tsc --noEmit` + 对应 `verify-*` 脚本通过。
