## 2. 本轮自查发现并修掉的自身缺陷（N185 内）

1. **符号语义反了**：首版按「`invert` = 数值变小是好事」写符号，实测读成 `受伤 +1.0%`（减伤写成加伤）、
   `闪避CD +0.20s`。根因是数据里两种约定混用——`takenMul` 每点 **−0.01**（带符号系数，负 = 少受伤），
   而 `skillCd` / `dodgeCdCut` 每点存的是**正数削减量**（0.02 / 0.4）。改为按字段声明 `dir: -1`
   只对后者取反，`takenMul` 直接用数值本身；`skillCd` 单位同时从 `sec` 改回 `pct`。
   修正后读回 `受伤 −1.0%`、`技能CD −2.0%`、`闪避CD −0.40s`。
2. **预览大面积为空**：`EFFECT_DISPLAY` 只覆盖 19 / 29 个效果字段，压制 / 钢铁阵型 / 钢铁意志 /
   荆棘堡垒 / 眩晕 / 减速等格子行末没有预览。补 10 个字段（`counterReflect` / `thornAoe` /
   `ccResist` / `lowHpDamage` / `burstShield` / `burstTaken` / `stackDamage` / `slowBonus` /
   `stunBonus` / `armorBreakBonus`）。**`cheatDeath`（不朽，每 2 点 1 次）刻意不补**：
   单点数值写不出「每 2 点」的语义，写了反而误导；该格仍只有名字 + 描述。
