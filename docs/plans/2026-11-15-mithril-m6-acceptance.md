## 2. 交付内容

### 2.1 纯逻辑（无 `cc` 依赖，可 node 自检）

| 文件 | 内容 |
|---|---|
| `MithrilConfig.ts` | 24 种敌人（15 普通 + 9 BOSS）；`DUNGEON_ENCOUNTERS`（6 副本 × 3 遭遇）；`DUNGEON_BOSS_SCRIPTS`（6 个三阶段脚本，打断 / 召唤 / 转火 / 追踪）；`DUNGEON_LOOT`（6 份首通紫装，一槽一件、装等跟着副本走）；`DUNGEON_SCALE`；`dungeonRunPlan()` 通用化；`ClassKitDef` 新增 `dr / contactDr / killHealPct` |

| `MithrilWild.ts` | 区域副本入口层（第 4 层）按「已实装副本数」开门，不再由种子挑一个（此前每区域总有一个副本进不去） |
| `MithrilArt.ts` | 8 种新敌人画法（`REGION_ART`）：教堂系圣白旧金、冰霜巨人、熔炉铁锈、暗影分身 / 刃、秘银王 |

### 2.3 数值口径（M6 新增 / 调整）

| 项 | 值 | 说明 |
|---|---|---|
| 敌人总数 | 24（15 普通 + 9 BOSS） | 灰烬荒原 5 + 副本专属 8 + 旧 BOSS 复用 |
| 副本 | 废弃矿坑 / 腐化教堂 / 冰封哨塔 / 熔火熔炉 / 暗影回廊 / 秘银王座 | 各 3 遭遇 + 1 BOSS；`DUNGEON_SCALE` 后两个 0.7 / 0.72 |
| 打断阈值 `interruptNeed` | 40 / 50 / 60 / 70 / 80 / 90 | 按最慢职业 DPS × 读条时长 ≈ 0.6 反推（旧值 100–900 对法师/牧师不可达，必然狂暴） |
| 召唤物回血 `addsRegen` | 10–20 /s | 必须低于最慢职业 DPS（游侠 ≈ 67），否则「清召唤物」在数学上不可能 |
| 职业护甲 | 战士 `dr 0.15 + 近战 0.35`；游侠 `0.10 + 击杀回 3.5%`；牧师 `0.08`；法师 `0` | 板甲站近战位靠减伤而不是堆血条；游侠靠击杀回复补 sustain |
| 玩家弹道追踪 | 普攻 3.4 rad/s、技能 2.2、箭雨 1.2 | 手机端没有瞄准输入，弹道必须追移动目标，否则实战 DPS 只有木桩的一半 |

## 6. 自查发现与修复（M6 期间）

| 类型 | 问题 | 修复 | 复验 |
|---|---|---|---|
| 平衡（阻断） | `interruptNeed` 100–900 对法师/牧师不可达 → 必然狂暴 → 后期副本必死 | 降到 40–90（≈ 0.6 × 最慢职业 DPS × 读条时长） | 24/24 通关 |
| 平衡（阻断） | `addsRegen` 最高 95 > 游侠 DPS 67 → 召唤物在场时数学上无法推进 | 降到 10–20；暗影回廊召唤物改用 2 × `shade_blade` | 暗影回廊 4 职业全通 |
| 逻辑（阻断） | 召唤物在场时 `_mechanicTimer` 继续累加，清完最后一只立刻重刷 → BOSS 永远停在 phase 1 | 召唤物存活期间计时器归零 | 矩阵 22/24 → 24/24 |
| 逻辑 | 手机端无瞄准输入，玩家弹道打不中移动目标（实战 DPS 只有木桩一半） | 玩家弹道加追踪（普攻 3.4 rad/s） | 木桩 DPS 与实战差距收敛 |
