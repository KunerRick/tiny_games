# 《秘银远征》M7 实施计划（20 饰品 + 12 协同）

> 日期：2026-11-15 · 分支：`develop` · 设计规格：`docs/plans/2026-11-14-game-mithril-design.md` §7 / §10 饰品组 / §4 构筑差异判据
> 前置：M6 已验收（`2026-11-15-mithril-m6-acceptance.md`）

## 退出判据

1. **20 件饰品逐件有可观察的规则效果**（不是无条件数值）：纯逻辑自检里每件至少一条断言，读的是战斗状态/事件，而不是面板乘数。
2. **12 条协同只能按配对点亮**：同 tag 两件不点亮；点亮后效果同样可观察。
3. **获取闭环**：20 件都在 6 个副本的 BOSS 掉落表里（每件恰好一处来源），掉落优先未拥有的；2 格装备/卸下/替换可用，存档往返不丢、不重复。
4. **构筑差异**：同一档装备与等级下，「带饰品（含协同）」与「不带饰品」的 60 秒木桩 DPS 差 **≥ 25%**（设计 §4 判据 2）。
5. **4 职业 × 6 副本自动战斗矩阵**在「带饰品」「不带饰品」两组下仍全通关，无 NaN、无卡死。
6. **浏览器实点**：从背包装备两件 → 协同名点亮；进副本能看到至少两种饰品触发的可见效果（雷击 / 爆炸 / 护盾 / 拾取范围）；卸下后协同熄灭。
7. **试玩循环 P0/P1 清零**（第 16 轮起）。

## 现状盘点（M6 结束时）

| 已有 | 缺 |
|---|---|
| `TRINKETS` 20 件 + `SYNERGIES` 12 条 + `findSynergies()`（Config 层完整，10 tag × 2 件，无 tag 重复） | 全部只是文案，**没有任何一件有效果** |
| 存档 `trinkets: [id, id]` + `sanitizeSave` 去重 | 无获取途径、无装备入口 |
| `trinketMultiplier()` 无条件 1.0–1.2×（`MithrilTalents.ts`，Core 用它乘攻击力） | 与设计「不提供任何数值」冲突，必须拆掉 |
| Core 已有燃烧 / 冻结（`status.stun`）/ 护盾 / 暴击 / 闪避 / 血球 / 敌人击杀 / 近战接触伤害等钩子 | 缺统一的「饰品效果分发」层与触发点 |
| 渲染层有子弹 / 预警 / 血球 / 伤害数字 / 屏幕震动 | 缺雷击、爆炸、隐身等视觉表现 |
| `MithrilMenu`（装备 + 背包）已有 8 槽装备、列表、装备/卸下/出售 | 饰品 2 格与拥有列表没有位置 |
| BOSS 重复掉落走 `bossLoot()`（随机紫装） | 掉落表里没有饰品 |

## 子步骤

### M7.1 效果引擎骨架（先立规矩，再填 20 件）

**新文件 `MithrilTrinkets.ts`（纯逻辑，不 import cc）**
- `TrinketFx`：统一上下文对象（world 引用、玩家、当前时间、rng），提供 `heal / shield / reflect / explode / lightning / addOrbs / spendResource` 等受控动作，**所有效果只经过这个上下文**，便于断言与防止效果互相踩状态。
- `FIRE` 注册表：`Record<trinketId, TrinketHooks>`，钩子点先定死一组：
  - `onEquip(world)` / `onCalc(profile)`（静态：暴击、移速、拾取范围、冰霜范围）
  - `onBasicHit / onSkillHit / onCrit / onDodge / onDamagedMelee / onEnemyKilled / onOrbPicked / onSkillCast(slot, n)`
  - `onSecond(world, dt)`（低血、静止、雷击计数）
  - `onNodeStart(world)`（每副本重置一次性的守誓者）
- `trinketFxOf(save)`：读 `save.trinkets` 返回一个聚合对象；**同一件不叠加**（存档层已去重，这里再兜一次）。
- `litSynergies(save)`：包 `findSynergies(tags)`，额外返回稳定排序，供 UI 与断言使用。

**Core 接线（`MithrilCore.ts`）**
- 构造时建 `this.trinkets = trinketFxOf(save)`；`_resetEncounter()` 调 `onNodeStart`。
- 在既有触发点插入钩子（每条都有现成位置，不新造系统）：
  - `_damageEnemy` 后 → `onBasicHit` / `onSkillHit`（吃 `res.crit`）
  - `hitPlayer` 内 → `onDamagedMelee`（只在 `opts.melee`），护盾吸收前后都要能看到原始伤害
  - `_dodge` 成功 → `onDodge`
  - 敌人死亡出球处 → `onEnemyKilled`
  - 拾取血球处 → `onOrbPicked`
  - 技能释放成功 → `onSkillCast`
- **删除** `trinketMultiplier` 对 `attackPower` 的无条件乘法；`estimateDps` 静态模型改为标注「饰品上限 ≈ 1.20×，条件是机制触发」，数值不改（它是估算器，不是战斗真值）。
- 快照补 `trinketProcs: string[]`（最近 1 秒触发的饰品/协同 id），供 HUD 与探针读。

### M7.2 20 件饰品（每件都要能被断言）

| 饰品 | 实现要点 | 可观察量 |
|---|---|---|
| 嗜血护符 | `hp<30%` 时技能冷却按 ×0.6 计 | 同一技能两次施放间隔 |
| 血契指环 | `+6% × floor(lostHp/10%)`，最高 +30% | 伤害数字与基线比 |
| 静默之铃 | 闪避后 1s 内下一次技能 `guaranteedCrit` | 事件 `crit:true` |
| 暗影披风 | 静止 2s → `hidden`，首次攻击 +80% 并解除 | 首击伤害、`hidden` 状态 |
| 回响石 | 每第 3 次施放同一槽位不耗资源 | 资源前后差 |
| 共鸣水晶 | 技能暴击 50% 重置该槽冷却 | `cd[slot]` 归零 |
| 荆棘之冠 | 近战反弹 20%，移速 ×0.9 | 敌人掉血、移速 |
| 反伤甲片 | 受伤对 80px 内敌人造成 15% | 周围敌人掉血 |
| 贪婪之眼 | 掉落 +1，降品质概率 +25% | 结算件数 / 品质分布 |
| 拾荒者背包 | 宝箱多 1 个选项，多扣 5% 生命 | 宝箱选项数、HP |
| 余烬之环 | 燃烧可叠 2 层（`burnDps` 叠加、时长取最大） | `burnDps` 值 |
| 烬火石 | 击杀燃烧中敌人 → 60px 爆炸 | 周围敌人掉血 |
| 霜华坠饰 | 冻结目标受伤 ×1.25 | 伤害对比 |
| 寒冰之心 | 冰霜技能半径 ×1.4 | 命中数 |
| 雷暴图腾 | 每 5 次命中落雷 80 伤害 | 第 5 次命中后敌人掉血 |
| 电荷护腕 | 暴击后 1s 普攻间隔 ×0.67 | 普攻次数 |
| 守誓者徽记 | 每副本首次死亡 → 不死、回 30% | `phase` 仍 `playing` |
| 誓约之链 | 治疗溢出转护盾（≤20% 生命） | `shield` |
| 饥饿之胃 | 血球拾取半径 ×1.3，治疗 ×0.85 | 拾取距离、回血量 |
| 食腐者吊坠 | 击杀精英回 10%，普通怪不回 | HP 变化 |

> 约束：**每件只改一条规则**，代码里逐件一个 `case`，禁止在钩子里写「顺便 +5% 伤害」。掉落 / 金币类效果必须走 `MithrilLoot` 或 `MithrilWild` 的现有出口。

### M7.3 12 条协同

- 点亮判定沿用 `findSynergies`（tag 配对、顺序无关、同 tag 不算）。
- 效果挂在同一 `TrinketFx` 上，用 `synergy:<id>` 前缀记 proc：
  - 血燃：低血时 `burnDps` ×2；影回：闪避后 1s 技能不耗资源；守财：反弹伤害 20% 转金币；冰雷：冻结目标被雷击时对 60px 传导；誓血：有护盾时伤害 +15%；饕餮：贪婪额外掉落时回 3% 生命；雷火：燃烧目标被雷击点燃周围；影刺：背刺 +40%（判定沿用朝向点积）；誓回：重置冷却时给 3% 护盾；寒食：冻结目标死亡掉血球；雷音：每 3 次雷击一次全屏 60 伤害；血食：`hp<50%` 拾取半径 +80%。
- 协同**不叠加同 tag 的第二件**：`save.trinkets` 两件同 tag 时协同列表为空（有断言）。
- 面板显示：已装备两件的 tag 与点亮协同名 + 效果文案；未点亮时显示「差一个 xxx tag」。

### M7.4 获取与 UI

**掉落（`MithrilConfig.ts` + `MithrilLoot.ts`）**
- 新增 `TRINKET_LOOT: Record<dungeonId, string[]>`，20 件各归一处：矿坑 3（血/荆棘/贪婪）、教堂 3（誓约/饥饿/回响）、哨塔 3（霜/暗影）、熔炉 3（烬火/血）、回廊 4（暗影/回响/贪婪/雷）、王座 4（雷/回响/饥饿/荆棘）。
- `rollTrinket(rng, save, dungeonId)`：先给未拥有的，全部拥有后退化为金币；`bossLoot` 返回结构加 `trinket?: string`（首通必给本副本未拥有的一件，重复通关 25% 概率给）。
- 结算行：`获得饰品：雷暴图腾（雷）`，与装备掉落行并列。

**面板（`MithrilMenu.ts`）**
- 顶部加「装备 / 饰品」切换；饰品页 = 2 个槽 + 拥有列表（名称、tag 色点、效果文案、已装备标记）。
- 装备/卸下走 `MithrilLoot` 新增的 `equipTrinket(save, id, slot)` / `unequipTrinket(save, slot)`，同一件不能占两格。
- 页脚一行协同栏：`协同：雷火（烬火 + 雷暴）`，未点亮显示提示。
- 所有 handler 命名方法、面板 `show()/open()` 里绑定（AGENTS 教训 E/H）。

**HUD（`MithrilHud.ts`）**
- 资源条下方一行小字显示最近一次饰品/协同 proc（1.5s 淡出），例如「雷暴图腾 · 落雷」。不改布局高度，不加图标字符（红线 10）。

**渲染（`MithrilRenderer.ts`）**
- 复用现有特效通道新增三种：落雷（一条竖线 + 白闪）、爆炸（圆环扩散）、隐身（玩家整体 alpha 0.35）。都画在特效层，不新建节点。

### M7.5 验证

**新脚本 `tools/verify-mithril-trinkets.js`**
1. 配置：20 件 / 10 tag × 2 / 无重复 id / 12 条协同两两不同 / `TRINKET_LOOT` 恰好覆盖 20 件且每件一处 / 每件效果文案非空。
2. 协同：枚举 45 对 tag，只有 12 对应点亮；同 tag 对不点亮；单件不点亮。
3. **逐件效果**：每件构造一个最小场景（木桩或固定敌人），跑固定帧数，断言 §M7.2 表里的可观察量；同一场景无饰品基线对照。
4. 协同效果：12 条各一条断言（可共用场景）。
5. 掉落：每副本首通必给未拥有饰品；给满 20 件后掉金币；存档往返保留。
6. 构筑差异：同档装备，60 秒木桩「无饰品」vs「血契 + 雷暴」DPS 差 ≥25%。
7. 矩阵回归：4 职业 × 6 副本 × {无饰品, 带两件} 全通，无 NaN。

**回归**：`verify-mithril-core.js`（预计 `_damageEnemy` 钩子改动后需要核对既有断言）、`-wild.js`、`-camp.js`、`-dungeons.js` 全绿；`tsc --noEmit` TS_OK。
**浏览器实点**：装备→协同点亮→进副本看 proc→卸下→熄灭；随后试玩第 16 轮（fresh 子代理）。

## 数值红线

| 项 | 上限 | 原因 |
|---|---|---|
| 饰品总 DPS 增益 | 条件全满足时 ≈ 1.20× | 设计 §4 四层倍率，饰品只负责「规则」 |
| 无条件常驻增益 | 0 | 设计 §7.1「不提供任何数值」 |
| 单条效果触发频率 | 落雷 ≤ 1 次/2s，爆炸 ≤ 1 次/0.5s | 防止高攻速下特效刷屏与数值超模 |
| 护盾类合计 | ≤ 35% 最大生命 | 誓约之链 20% + 誓回 3% + 守誓者 30% 不同时存在，但有交叉 |

## 风险

| 风险 | 应对 |
|---|---|
| 20 个钩子散落进 Core 变成意大利面 | 所有触发点只调 `this.trinkets.onX(...)`，效果实现全在 `MithrilTrinkets.ts` |
| 删掉 1.2× 无条件乘数后矩阵崩 | 矩阵本来不带饰品（`profileFromSave` 空 trinkets），先跑基线确认不受影响 |
| 面板再踩 AGENTS 教训 C/E/H | 复用 `MithrilMenu` 既有列表工厂；用具名方法；遮罩层级沿用现有面板 |
| 效果数值超模 | 每条断言都写「上限」而不只是「有触发」 |
