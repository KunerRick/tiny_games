## 4. 方法与数据说明（必读）

### 4.1 视口与坐标换算（本轮现场标定，`k = 1`）

| 项 | 值 |
|---|---|
| 视口 | 1280 × 720 |
| `#GameCanvas` rect | `{x: 443.5, y: 41.453, w: 393, h: 678.547}` |
| canvas 缓冲区 | 393 × 679 |
| `devicePixelRatio` | 1 |
| 点击入参 | `page.mouse.click` 直接吃 CSS 坐标（1:1，k = 1） |

世界 → CSS：`ui.convertToWorldSpaceAR(new cc.Vec3(0,0,0))` → `camera.worldToScreen(...)` → `cssX = rect.left + sp.x / canvas.width * rect.width`、`cssY = rect.top + (1 − sp.y / canvas.height) * rect.height`。本轮未出现偏移。

### 4.2 探针（只读，每次 reload 后重注入）

`window.__r15 = { root, comp(name), byPath(name), cssOf(node), g, wild, hud, cls }`；`comp` 按 `constructor.name` 在 `Canvas/GameRoot` 子树里找组件。读取字段：`g._save`（level / exp / gold / materials / skillBooks / dungeonsCleared / inventory / equips / expedition）、`g._mode`、`g._wildMap.nodes[*]`、`g._lastSnapshot`（phase / time / player（hp、rage、holy、cd、burst）/ enemies / boss（hp、maxHp、phase、casting）/ bossCast / bossHint / bossPhaseCount / dungeonName / dungeonProgress / telegraphs / orbs）、HUD 的 Label 文本。

**易错字段**：快照里**没有 `bossPhase`**，阶段要看 `boss.phase`（0 基）或 HUD「阶段 N/3」；`player.rage` 是通用主资源（怒气 / 法力 / 能量），牧师的圣能是 `player.holy`；`bossCast` 的键是 `[name, total, remaining, need, taken]`，`taken >= need` 即打断成功。

## 5. 未复现 / 已排除的疑点

1. **「Wild_3 / Wild_6 / Wild_10 点了没反应」——不是缺陷。** ① `Wild_3` 是**事件**节点，点击后弹出「路边事件」选择面板（搜刮物资 / 包扎伤口 / 冒险深挖），地图仍在背后 `activeInHierarchy = true`，弹窗遮罩吞掉了后续点击（所以点到 Wild_6 / Wild_10 毫无反应）；② `Wild_10` 从一开始就与当前位置**不相邻**（图：`6→{3,9}`），只有绿线相邻节点可点。处理掉事件弹窗、并按中列 `0→2→5→8→10` 走之后，教堂正常进入。
2. **「U（破）按键不进冷却」——不是缺陷。** 破甲需要 150 内有目标；目标刚被 L 清掉的瞬间空放不触发、也不进冷却（`cd.armorBreak` 保持 0）。有目标时实测冷却 11.46s。
3. **「战士爆发不消耗怒气」——不是缺陷。** 持续普攻下怒气约 1 秒回满，4–6s 采样看起来恒为 100；精确读取得 100 → 10、`burst 9.67s`、`cd.burst 38.7s`。
4. **「教堂 BOSS 召唤的修女不掉血」——未能归因，不作为缺陷。** 2 只 `chapel_acolyte` 在 22 秒内血量恒为 130，同段时间 BOSS 血量缓慢下降；自动驾驶在追最近的敌人，无法判断是站位 / 攻击目标选择还是小怪不可选中。
5. **「副本难度过高」——不作为缺陷。** 固定档 `equips` 全为 `null`（首通紫武只在背包未装备），角色是无装备的 Lv17，BOSS 战 DPS 仅约 25–29，不能据此判定副本数值过强；且开工时的真实档 `dungeonsCleared` 已含 `chapel`，说明可通关。
6. **「阵亡结算仍显示『可成长：天赋点 / 技能书』」——非缺陷**：数值确实未变，属提示信息。
7. **「弹窗期间地图还能看到节点」——非缺陷**：`WildModal` 带 `BlockInputEvents` + alpha 235 遮罩，属模态设计。
