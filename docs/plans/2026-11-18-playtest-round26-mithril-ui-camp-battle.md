## 1. 结论摘要

用户的诉求是「层级不协调」，落到具体界面上是三类问题：**同一层级的东西被画成两种样式**、**上下级的东西被画成同一个重量**、**文字压在可变色背景上没有对比**。本轮逐条对齐：

1. **营地军需官**：原来一行塞下「悬赏板 + 条数 + 两条规则」，标签层直接和描述层糊在一起 → 拆成「分组标题 + 右上计数 + 底部注脚」三层，并删掉与设施块重复的「下一级」。
2. **战斗提示条 vs 标题牌位**：两者原本都是「同宽圆角石卡 + 金框」，上下只隔 21px，读起来像一张拼歪的卡 → 提示条降级成**二级飘带**（暗底 + 上下收短的细金线 + 左端菱形题花），标题牌位下移并把间距拉到 69px，一级/二级一眼分得开。
3. **文字与底色**：金/橙宝石技能键上的羊皮纸字只有 2.5–3.0:1，血条与资源条数值压在同色填充上（满槽 1.5:1）→ 前者改用墨色（5.4 / 4.5:1）并给图形分档不透明度，后者用 Label 自带描边把字形从底色里抠出来。
4. **材质连通**：单位框底板 172α 在战场上等于没画（框读不出来）→ 228α + 黄铜框；左上返回键是最后一块全站深蓝圆盘 → 换成石盘 + 金环 + 羊皮纸箭头。

**第二拍（复核回修）**把「层级」这件事从头量了一遍，补上自检漏掉的两类：

5. **文字压在会变色的填充上**：怒气满槽 1.52:1、冷色技能键 3.4–4.3:1、品质正文 3.35–4.04:1 → 填充色本身压深过 AA，亮色只留给描边/光带；品质色拆出「文字档」。
6. **营地「同一件事播两遍」与「一行塞四件事」**：升级区拆成「等级读数 / 成本 / 进度」三层，厨房一行拆成三级，五页板底留白统一到 24px —— 用户在页签之间切时内容不再跳。
7. **结算面板**从「8 行同号同色」改成「上下文（暗）— 金线 — 收益（亮）— 按钮」四段。

## 5. 独立复核

复核者为 fresh 子代理（无本轮开发上下文，只有用户原话与报告路径），在 1:1 视口下逐页巡检 + 页内探针量色/量边 + 真实点击，结束 `browser_close`。共提 **15 条**（P2 × 8、P3 × 7）；修复过程中自检又补记 1 条（N130）。合计 16 条编号 N117–N132：**修 10（N117–N126）／接受 1（N127）／转下一拍 5（N128–N132）**。

### 5.1 复核确认「本轮自检漏掉」的四类（P2）

1. **对比度只算了「正文底」，没算「可变填充」**（N117 / N119）。我在 N113/N115 修了暖色宝石与血条，但复核把 HUD 上**所有**有字压着的填充都算了一遍：怒气满槽 `#E8B04B` 上的羊皮纸字 **1.52:1**、法力 4.06、能量 3.18；技能键冷色三枚 3.38 / 4.11 / 4.31。教训：描边是兜底，不是合格线 —— 填充色本身要先过 AA。
2. **品质色直接当正文**（N118）。圆点/图标用 WoW 原色没问题，但列表行与详情标题用同一色：史诗 `#A335EE` 3.35:1、稀有 `#2A7FDE` 4.04:1。复核漏了 `mythic #E03A3A`（3.4:1），我补齐。
3. **右对齐失效**（N120）。三行都写了 `align:'right'`，但 `createLabel` 默认 `Overflow.NONE` 会按内容宽度收窄节点、仍以 x 为中心 → 右边缘 590 / 612 / 597 参差。这是 N89 同一坑第三次出现，故写进教训。
4. **营地「同一件事播两遍」**（N121 / N122）。升级区按钮、提示、等级读数三处都在讲「还差多少升到几级」；厨房一行塞「菜名 + 效果 + 价格 + 持续」四种信息、同号同色。复核的原话是「读成一坨」。

### 5.2 复核提出的层级缺口（P2）

5. **结算面板没有层级**（N123）：落败时 8–11 行一个字号一个颜色，地点 / 用时 / 收益三段读不出来。
6. **营地五页板底留白 7 / 6 / 19 / 72 / 104px**（N124）：切页签时内容块在跳，用户说的「不协调」有一半来自这里。

### 5.3 复核的 P3（7 条）

N125 铁匠两键整组右偏 40px（已修）、N126 附魔首/末页的翻页键不置灰（已修）、N127 空态标题大于分组标题（接受，见 §5.4）、N128 厨房「生效中 / 下一场加成」分居两处、N129 军需官悬赏行奖励不右对齐、N131 返回键三种形制并存、N132 铁匠/附魔两列行高不一致。
