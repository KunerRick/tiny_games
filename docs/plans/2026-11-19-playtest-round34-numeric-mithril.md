## 0. 结论摘要

1. **N184 的断崖不是「数值总量不够」，是一次闪避检查。** 同一套 Lv5 / 2 槽 / ilvl3 的角色：
   - 只普攻、不躲预警圈：**0/24 胜**；
   - 会按技能、仍不躲预警圈：**18/24 胜**；
   - 会技能 + 会躲（bot）：**24/24 胜，BOSS 全程只承伤 8 点**。
   装等、等级、槽数都没变，差别全在「是否在 1.1 秒内走出砸地红圈」。
2. **小怪段结构上不可能影响 BOSS。** 全副本可回血 = 3 次遭遇 ×25% + 2 次阶段转换 ×20% =
   **115% 最大生命**，而矿坑小怪总战损只有 **5–26%**（3 槽、ilvl1–10）。第一次遭遇后的回血
   （25%）就足以抹掉整段小怪的伤害。
3. **N177 的「1–10」不能用一个数字修好。** 矿坑 2–3 槽时，10 个装等档全部到不了「4 职业最差 ≥60%」
   （3 槽最好的一档是 ilvl10 的 33%）；8 槽 + 会按技能时，ilvl4 起最差职业才稳定在 58–75%，
   而**游侠这条曲线在 58–75% 之间随机波动（n=12，95% CI ≈ ±28pp），与装等不相关**。
   原因是游侠的基础 DPS 最低（1.643 vs 法师 1.875 / 牧师 1.800 / 战士 1.833），
   而它的能力预算在「后跳 / 陷阱 / 加速」这些主动技能上，普通玩家不用就吃不到。
4. **推荐：C（改文案，必做）+ B1（砸地 10→6、阶段回血 20%→30%）。**
   B1 对 033/036 零影响（bot 副本用时 136.1s 不变），且把 `verify-mithril-newplayer` E 从 5/6 提到 **6/6**。
5. **A（小怪加压）被现有闸门否决**：newplayer E 从 5/6 掉到 **4/6（FAIL）**。
   **B2（巨魔 1800→1500）不建议**：副本平均用时 −9.2%，会压 033 只剩 2.5% 的余量。

## 3. 根因（全部为实测/可复算数字）

### 3.1 BOSS 数值 × 玩家 DPS = 30 秒的缺口

- 巨魔 HP **1800**，阈值 2/3、1/3 → 每个阶段 **600**。
- 试玩档基础 DPS **23.3** → 理论 TTK **77s**；`noSkill` 实测 BOSS 段约 **72–75s**（含召唤回血）。
- 不躲圈时可用生存窗口 **≈42s**，期间打出约 **970** 伤害（BOSS 剩 46%）。
- **缺口 ≈ 30–35s（需求时长の 40–45%）**：不是「再打两下就过」，而是「必须把承受伤害砍半」。

### 3.2 打断是硬 DPS 门槛

- `interruptNeed=100` / `interruptCast=3s` → **33.3 DPS**。
- 试玩档基础 DPS **23.3** → **1.43× 缺口**；只普攻**必然打断失败**。
- 失败 → `enrageBonus 0.5`，BOSS 伤害 ×1.5 持续 **10s**（≈ 再多吃 1.5 次砸地 + 弹道）。
- 这解释了为什么「只普攻」在第 3 阶段必死，也解释了游侠（基础 DPS 最低）为什么最差。

### 3.3 召唤阶段是「净 DPS 转负」风险

- 2 只矿工各 80 HP；`addsRegen=15/s`（**总计**，不是每只）且**召唤物在场时不重刷**。
- 以 23.3 DPS 清 160 HP 需 6.9s，其间 BOSS 回 **103 HP** → 每波召唤的净进度只有 ≈58 HP。
- 不转火（或转火慢）时，15/s 回血 ≈ 基础 DPS 的 64%，战斗被拖长 → 生存窗口先耗尽。

### 3.4 回血预算让「小怪压力」失效

- 可回血总量 = 3×25%（遭遇）+ 2×20%（阶段）= **115% maxHp**（试玩档 ≈198 HP）。
- 矿坑小怪总战损 = **18%（ilvl3，3 槽）≈31 HP**，**小于一次遭遇回血（43 HP）**。
- 实测：只把遭遇回血 25%→10%、不加怪（变体 A2），3 槽 ilvl3 的战士从 6/6 掉到 5/6，
  8 槽 ilvl8 完全不变 —— 反过来证明当前小怪伤害本来就在噪声内。

### 3.5 职业差距 = 技能表达差，不是面板差

四个职业的 `ap / maxHp / basicDps` **完全相同**（`profileFromSave` 不含职业系数）。
差别只在 kit：

| 职业 | 基础倍率/冷却 | 基础 DPS 系数 | 减伤 | 备注 |
|---|---|---|---|---|
| 战士 | 1.1 / 0.6s | 1.833 | 15%（接触 35%） | 近战，最耐打 |
| 法师 | 1.5 / 0.8s | **1.875** | 0% | 面板最高，脆 |
| 牧师 | 1.35 / 0.75s | 1.800 | 8% | 自带治疗 |
| 游侠 | 1.15 / 0.7s | **1.643** | 10% | 预算在后跳/陷阱/加速 |

游侠还有一层机制反噬：能量**站桩回 14/s、移动只回 6/s**，而矿坑 BOSS 每 6s 在脚下放圈、
逼你持续移动。**「站桩回资源」与「必须一直走」正面对冲**。这解释了 12 seed 下
游侠始终是 4 职业里唯一不收敛的那个（2–3 槽 42–75%，8 槽 58–75%，与 ilvl 无单调关系）。

## 5. 推荐

### 5.1 C（必做）：把「区间」改成「点估计 + 槽数 + 机制」

现状（`assets/games/game_mithril/scripts/MithrilGame.ts`）：

- L669：`推荐装等 ${def.ilvlMin}–${def.ilvlMax}　当前平均装等 ${cur.toFixed(1)}（${st.equipped}/8 槽）`
- L675：`警告：装等低于推荐下限 ${def.ilvlMin}，建议先清野外节点`

问题：`1–10` 把「ilvl1 也能进」写成了官方许可，而真实门槛是
**槽数 ≥3 且会躲砸地圈**。数据上，同是 ilvl3.0，2 槽 0/24、8 槽 17/24（`noSkill` 口径）。

建议改为：

```
建议 平均装等 ≥8 · ≥3/8 槽　当前 3.0（2/8 槽）
首领：砸地红圈必须走出去（1.1 秒预警）
```

警告条件从 `ilvl < ilvlMin` 改为 **`ilvl < 8 || equipped < 3`**。
（若产品希望文案更短，至少要把「≥3/8 槽」和「走出红圈」两条留下；这两条比装等数字更能预测成败。）

> 为什么是 8 而不是 5：`noSkill` 口径下 3 槽 ilvl3/5/8 的最差职业都是 **0%**，ilvl10 才到 33%；
> `skills` 口径（12 seed）下槽位比装等更决定结果 —— 8 槽 ilvl2 起游侠就有 58%，
> 但 5 槽会掉回 ilvl5 的 67% → ilvl8 的 25% → ilvl10 的 58%，**不单调**。
> 所以「≥8 装等」单独一条并不够，必须和「≥3/8 槽」成对出现；
> 两者合写在 `noSkill` 与 `skills` 两种口径下都成立。

### 5.2 B1（推荐）：降低「不会躲圈」的死亡惩罚

```ts
// MithrilConfig.ts · MINE_BOSS_SCRIPT
moveDamage: 10 → 6,        // 砸地
// MithrilConfig.ts · BOSS_PHASE_HEAL_PCT
0.20 → 0.30
```

预期（实测）：

- 试玩档（Lv5/2 槽/ilvl3）从 **0/24 → 5/24**（战士先过）；死亡点从 39% → 34%。
- 3 槽 ilvl8 的战士/法师/牧师从 6/0/1 → 6/1/4（游侠 1/6）。
- 8.0 档不回归（最差仍 83%）。
- **033/036 零影响**（bot 副本用时 136.1s 不变）；**newplayer E 5/6 → 6/6**。

### 5.3 不建议

- **A（小怪加压）**：被 newplayer E 直接否决（4/6 FAIL），且在 8.0 档制造了新的
  「小怪段死亡」失败模式。小怪段本来就不是这次失败的成因（§3.4）。
- **B2（巨魔 1800→1500）**：虽然能把试玩档推到 5/6，但副本平均用时 −9.2%（136.1→123.6s）。
  按 033 的分段（六个副本合计 0.68h / 40.8min）等比折算约 −3.8min，而 033 的总余量只有
  **108s（1.8min）** —— **余量会被吃掉两倍以上，033 有较大概率直接掉到 1.20h 以下**。
  （这是按分段占比的估算，**未实测**；见 §7 未测格 5。要采纳 B2 必须先跑 `verify-mithril-balance` 复核。）
  另外 B2 让 8.0 档最差职业从 83% 掉到 50%（阶段重定时），收益并不稳定。

### 5.4 需要主会话/设计决策的事项

1. **游侠的技能地板**：它是唯一在「会技能、不躲圈」口径下不收敛的职业（基础 DPS 最低 +
   能量站桩回复与「必须移动」对冲）。这需要设计决策（改能量回复 / 改基础倍率 / 给游侠一个
   被动减伤），**不是本次数值分析能单方面改的**。
2. **是否接受 B1 改变「BOSS 伤害」的设计语义**：砸地 10→6 会让「不躲圈」从致命变成可承受，
   可能削弱机制教学的力度。若更看重教学，替代方案是「保留 10 伤害、把预警从 1.1s 提到 1.4s」，
   但本次未模拟该变体（见 §7 未测格）。
3. **033 的口径**：本次实测 033 = **1.23h / 下限 1.20h（余量 2.5%，108s）**；
   036 = **2.59h / 下限 2.5h（余量 3.6%）**。任务描述里的「3.6%」属于 **036**，不是 033；
   两条约束应分开引用。

## 7. 未测 / 风险 / 声明

### 未测格（明确声明）

1. **暗影回廊 / 秘银王座的「≥60% 下界」无法用本模型反推**：`noSkill` 与 `skills` 两种口径下
   8 槽全装等都停在 0–25%（玩家在 BOSS 第 1 阶段就死）。它们的门槛是「必须躲机制」，
   不是装等，故报告不给数字下界。
2. **只测了矿坑的 12 seed 高样本**；其余五副本是 4–6 seed，二值胜率的 CI 约 ±25–40pp，
   表中间的小数差异不应被当作真实排序。
3. **未模拟的替代变体**：砸地预警 1.1s→1.4s、召唤回血 15→10/s、给游侠被动减伤。
   这些留作下一轮（尤其若主会话选择「保机制、降惩罚」而不是 B1）。
4. **饰品 / 天赋 / 料理全部未开**：本报告是裸装口径；真实玩家带饰品会整体上移。
5. **B2 对 033 的冲击只做了分段估算，没有实跑 `verify-mithril-balance`**（该脚本需改配置后重跑，
   属于「会动仓库」的操作，按本次只读约束未执行）。§5.3 的「吃掉余量两倍以上」是估算；
   若主会话考虑 B2，必须先实跑该闸门。

### 风险

- 模型是启发式的，「会技能、不躲圈」不等于任何具体真人；它的价值在于**和试玩读数标定过**
  （死亡点 46%、阶段 2/3），而不是绝对胜率。
- B1 同时改了两个参数，虽然做了消融，但消融用的是 6 seed，单项贡献的置信区间较宽。
- 阶段重定时会让「胜率 vs 血量/装等」非单调；任何后续调参都必须逐 seed 看，不能只看均值。
