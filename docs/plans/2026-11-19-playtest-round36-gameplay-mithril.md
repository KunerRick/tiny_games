## 1. 玩家日记（先写感受，后建表）

**第一段：我以为这游戏会告诉我怎么打。**
清完档进游戏，职业页只有一个选择摆在我面前（战士），点"以战士开局"就进了野外地图。地图上有一堆节点、三个地区页签、一条写着"起点"的线，我大概知道要往右走。点第一个战斗节点，进场横幅写着"左半屏拖动移动 · 按住「劈砍」边打边走 · 移动会自动朝向最近的敌人"。我照着"按住劈砍"做了，但没拖动——21 秒后我死了，击杀 0。第二次我还试了一遍，1 个击杀，又死了。直到死亡面板写"本局几乎没有移动：战斗中在左半屏拖动即可移动"，我才真正开始移动。**教程写对了，但我是死了两次才读进去的。**

**第二段：一旦开始动，游戏突然变得很好玩。**
第三把我按住普攻、用 WASD 绕圈（桌面端我用键盘代替左半屏拖动），三波小怪 53 秒清完，10 个击杀，升到 2 级，掉落了一件"史诗·牧师手套"。这件装备对战士来说名字有点怪，但面板写着"任何职业可穿"。我把旧的换下来，攻击 10.3 → 10.7，生命 78 → 98。**生命涨了 20 我看得见，攻击涨 0.3 我完全没感觉。**

**第三段：营地是这一趟最"像个游戏"的地方。**
铁匠铺按下去没反应——不，是有反应的：按钮下面写着"材料不足：需要 灰烬 ×3（现有 2）"。打到第三个节点凑够灰烬，升到 1 级铁匠铺，解锁了"重铸 58 金"，下一级要 灰烬 ×10。**这一屏我看得懂，也知道下一步该攒什么。**

**第四段：成长页让我第一次觉得自己在做选择。**
三条天赋线（钢铁 / 狂怒 / 战术），每条 5 层、每层二选一，门槛写"需5 / 需10 / 需15 / 需20"。我有 3 点：先给"坚韧"（受伤 −1%），再给"狂暴"两点（暴击 +1% → +2%），标题行立刻变成"天赋点：可用 0 · 已投 3/3"，卡片上的数字也跟着从 +1.0% 变 +2.0%。**点完第 4 下（点数已经为 0）什么也没发生，没有提示、没有抖动、没有"点数不足"——我以为点歪了。**

**第五段：篝火与副本门口，一个让我愣住，一个让我服气。**
篝火节点我以为是"补补给"的，结果进去补给从 1/3 掉到 0/3，弹窗才说"这里只恢复生命，不补充补给"。接着我去副本门口，弹窗把话说得非常清楚：建议平均装等 ≥8、装备 ≥3/8 槽；我当前 3.0、1/8 槽；首领机制是砸地 AoE、1.1 秒预警、走出范围；阶段是砸地 → 召唤矿工 → 狂暴读条；首通给经验 +800、技能书 +1、一件紫装；进入还要扣 9 点生命。**这是我这一趟看到的最好的一屏——它没有拦我，但把"你可能会死"说得明明白白。**

**第六段：我死在了第 3 波，连BOSS的面都没见到。**
副本 3 波，前两波 2 分 36 秒、17 个击杀，中途升到 4 级回了满血。第 3 波我被磨到 0，BOSS 从头到尾没有出现。死亡面板告诉我"本局收益 金币 +49 经验 +257""丢失 灰烬 ×3""可成长：天赋点 1"——**清算得很干净，也让我清楚下一局要先去刷装备。**

**第七段：回头再看，问题不在"有没有内容"。**
这一趟系统是齐的：地图、节点、事件、篝火、营地、天赋、装备、副本门槛、死亡清算，每一环都有文案、有结算、有下一步。真正卡住我的是两件事：**战场被拉得太远**（角色只有十几像素，砸地预警圈在截图里根本找不到），以及**打法与规划之间的信息不一致**（出发前地图上的"宝箱"，开始远征后变成了"战斗"）。前者让我打得心里没底，后者让我白规划了一条路线。

**规格偏差 / 观察**

- 副本门槛是"警告不拦截"：装等 3.0 也能进推荐 8 的副本，弹窗把差距写在最显眼处——这是好的设计选择，但**实际 TTK 差距很大**（3 波 2:36 仍死在第 3 波），说明"警告"与"可通关"之间的落差没有被别的机制填上（例如场内回复、逃课出口）。建议观察项而非缺陷。
