## 4. 本轮自查发现的两个自身缺陷

1. **N161 首版叠字**：洗点按钮第一次放在 y −436，与面板页脚提示 `_hintLabel`（y −438）重叠；
   截图 r33-02 可见两行字互相压住。改为「网格 → 数值 −340 → 洗点 −400 → 页脚 −450」后复测正常。
   （教训与 round31 N162 同源：字号 / 位置类修复**必须截图读字**，只读 `fontSize` 探针看不出来。）
2. **设计坐标当世界坐标**：第一次点页签补充热区时，直接用 `(220, 535)` 建 `Vec3` 送
   `worldToScreen`，结果点到地图节点（弹出「这个节点走不到…」）。地图节点与页签都有父级偏移，
   设计坐标 ≠ 世界坐标；正确姿势是取目标节点 `worldPosition` 再加偏移。第二轮改法后四处置信。
3. 走向事故：`(272, 418)` 被成长页与装备页**复用**，探针按坐标找「返回」时抓到隐藏的那个。
   以后按坐标找节点必须加 `activeInHierarchy` 过滤。
