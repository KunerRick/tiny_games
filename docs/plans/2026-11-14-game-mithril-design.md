# 《秘银远征》设计规格（2D 俯视 ARPG · 单机）

> 2026-11-14 立稿。目标：用本仓库已有的美术与逻辑体系，做一个**不缩水**的
> 「装备 / 饰品 / 野外 / 副本 + 养成」单机 ARPG。
> 定位：**Hades × 暗黑地牢 × 魔兽的成长循环**，不是魔兽的体量。
> 判定标准不是「像不像魔兽」，是「**刷一件装备会不会让你改变打法**」。

- id: `mithril` · sceneName: `Mithril` · 目录: `assets/games/game_mithril/`
- 预计规模：**12–16 个 ts 文件 / 13–16k 行**（对照：`game_fridge` 11 文件 / 8.5k 行）
- 美术：**零位图**，全部 `Graphics` 程序化绘制，主包零压力

## 1. 为什么这次不缩水

上一轮讨论砍掉的是**形态**（无缝世界 → 节点图、3D → 2D），这一版要保证的是**深度**：

| 维度 | 缩水做法（否决） | 本方案 |
|---|---|---|
| 装备 | 30 件，纯数值 +攻击 | 50 件基型 × 词条 roll，**30% 带「改造词条」**（改变技能行为） |
| 饰品 | 2 件 +20 属性 | 20 件**规则改写器** + 12 条组合协同 |
| 升级 | 一条线性等级 | 等级 + 天赋树（每职业 3 线）+ 技能 5 级 × 2 变体，三层正交 |
| 副本 | 随机房间堆 | 6 个手工副本，**每个 BOSS 3 阶段 3 机制**，考打断/转火/走位 |
| 野外 | 一关一关打 | 12 节点路线图，**路线选择 + 补给风险** |
| 成长 | 局内肉鸽 | **跨局永久**：营地 5 设施升级 + 装备库 |

核心判据：
1. **静态可验证**：30 级毕业装 DPS / 1 级白装 ∈ **[8, 11]**。已跑通 **9.53×**，常量由 `verify-mithril-core.js` 锁死。
2. **动态验证**：两套不同「天赋 + 饰品 + 技能变体」的构筑，60 秒木桩 + 副本全程实测 DPS 差 ≥ **25%**。
   **注意**：静态倍率模型证明不了这条——固定预算的线性副属性必然「均衡配点最优」（见 §4.3），
   构筑差异必须靠天赋/饰品/变体的机制效应，只能在 M3 的战斗 sim 里量。
3. 一件「改造词条」装备必须能让某个技能的用法发生可观察变化。

## 2. 核心循环

```
         ┌──────────── 营地（永久层）────────────┐
         │  装备库 / 天赋 / 铁匠铺 / 附魔台 / 厨房  │
         └───────────────▲───────────────────────┘
                         │ 材料 / 装备 / 图纸
      ┌──────────────────┴──────────────────┐
      │             野外（节点路线图）        │  ← 一次性消耗，有风险
      │  战斗 / 精英 / 宝箱 / 事件 / 篝火    │
      └──────────────────┬──────────────────┘
                         │ 进入
      ┌──────────────────▼──────────────────┐
      │          副本（固定关卡，可刷）        │
      │   3 遭遇 + 1 BOSS（3 阶段 3 机制）     │
      └─────────────────────────────────────┘
```

三档节奏：
- **5 分钟**：打一段野外，捡两件装备。
- **20 分钟**：打完一个副本，BOSS 掉紫装。
- **6 小时**：一周目（6 副本 + 24 悬赏 + 30 级）。

**风险设计**：野外死亡 → 丢失本次捡到的**材料**，保留装备（硬核但不劝退）。
副本死亡 → 退回副本入口，BOSS 重置。这是「刷本」必须的惩罚感来源。

## 3. 战斗（俯视实时）

### 3.1 架构（直接复用 `fridge` 的成熟模式）

```
MithrilCore (纯逻辑, 不 import cc)
  ├─ 固定步长 1/60 推进 (FIXED_DT)
  ├─ 实体上限: 敌人 ≤ 40 / 子弹 ≤ 300 / 掉落 ≤ 60
  ├─ 产出 MithrilSnapshot（只读快照）
  └─ 可被 node 脚本直接编译 → tools/verify-mithril-core.js

MithrilRenderer (Graphics)
  └─ 每帧 clear() → 按层重画 snapshot
      层序: 地面 → 墙/障碍 → 掉落 → 敌人 → 子弹 → 玩家 → 特效
```

**为什么这样分**：`fridge` 已经证明这套结构能扛 40 敌人 + 300 子弹的微信小游戏性能，
并且让 80% 的玩法（伤害、掉落、AI、BOSS 阶段）可以在**不启动编辑器**的情况下测。

### 3.2 操作（手机键位精简到 5 个）

| 输入 | 行为 |
|---|---|
| 虚拟摇杆（左） | 移动 |
| 摇杆（右） | 朝向 / 瞄准（远程职业用） |
| A 键（大圆） | 主技能（普攻/连段，自动朝向最近目标） |
| B/C/D 键 | 3 个主动技能（冷却制） |
| 闪避键 | 短位移 + 0.4s 无敌（有 CD） |

**目标选择**：近战自动索敌（最近 + 朝向锥形 90°）；远程按摇杆方向自由瞄准。
不做「点击选目标」——2D 俯视下点选手感差，且移动端误触高。

### 3.3 资源体系（每职业不同，这是职业差异的第一层）

| 职业 | 资源 | 机制 |
|---|---|---|
| 战士 | 怒气 0–100 | 造成/承受伤害积攒，技能消耗 |
| 法师 | 法力 0–100 | 缓慢回复，技能消耗，可「唤醒」快速回蓝 |
| 游侠 | 能量 0–100 | 快速回复，移动时恢复更慢（站桩输出） |
| 牧师 | 法力 + 圣能 | 治疗积攒圣能，圣能放爆发 |

### 3.4 技能（4 职业 × 6 技能 = 24）

每职业固定结构：**1 基础 / 3 主动 / 1 闪避 / 1 爆发**。
每个技能 **5 级**，在 **2 级 / 4 级**各解锁一次**变体二选一**（不可回退）。

```
例：法师「火球术」
  Lv1 基础：60 伤害，单体
  Lv2 变体 A「炽热」：命中后 3 秒内持续 30 伤害
  Lv2 变体 B「爆裂」：命中后 60px 范围 40 伤害
  Lv4 变体 A「连锁」：命中后弹射到最近敌人（50% 伤害）
  Lv4 变体 B「聚焦」：飞行变慢但伤害 ×1.6
```

**这一层是 build 深度的主要来源**：4 职业 × 6 技能 × 2×2 变体 = 96 个技能形态，
再乘装备改造词条与饰品协同，构筑空间远超「数值堆叠」。

## 4. 升级体系（重点：算成硬账）

### 4.1 五层倍率（已跑通，乘积 9.69×）

> 下面的倍率不是拍脑袋的：核算脚本把两个锚点跑出来是 **9.53×**，落在 8–11 区间；
> 副属性在 ilvl40 均衡配点恰好触顶、零浪费。实现时这些常量进 `MithrilConfig.TUNING`，
> 由 `verify-mithril-core.js` 锁死。

| 层 | 满配贡献 | 说明 |
|---|---|---|
| **角色等级** 1–30 | **2.00×** | 基础攻击强度 + 技能系数随级增长 |
| **装备·主属性** ilvl 1–40 | **1.60×** | 武器/护甲的 AP 部分 |
| **装备·副属性** ilvl 1–40 | **1.87×** | 暴击/急速/精通/全能 均衡到 caps |
| **天赋** 30 点 | **1.35×** | 每职业 3 线，见 §4.5 |
| **饰品** 2 格 | **1.20×** | 规则改写器 + 少量协同倍率 |

**装备合计 2.99×**（1.60 × 1.87）。四层互不替代：等级给底子、装备给上限、天赋给方向、饰品给规则。
**技能变体不计入倍率**——它改变形态，不改变数值。

实测档位（相对 1 级白装）：

| 等级 / 装等 | 天赋 | 饰品 | 相对 DPS |
|---|---|---|---|
| 1 / 1 | 0 | 0 | 1.00× |
| 5 / 5 | 3 | 0 | 1.34× |
| 10 / 10 | 8 | 1 | 2.08× |
| 15 / 20 | 15 | 1 | 3.37× |
| 20 / 28 | 20 | 2 | 5.34× |
| 25 / 34 | 26 | 2 | 7.26× |
| 30 / 40 | 30 | 2 | **9.53×** |

### 4.2 角色等级曲线

```
基础攻击强度(lv) = 10 × (1 + (lv−1)/29)      // 10 → 20，贡献 2.0×
最大生命(lv)     = 60 + 18 × (lv−1)          // 60 → 582
经验(lv→lv+1)    = 50 × lv^1.35             // lv1→30 累计 ≈ 60,500
天赋点           = 每级 +1                    // 30 级共 30 点
```

> 注意：等级只贡献 2.0×，**不是** 3×。装备（2.99×）才是主要成长源——这是刻意对齐
> 魔兽「满级才是开始」的手感：1→30 级的爬升平缓，真正的墙在装备与构筑。

经验来源：普通怪 12 / 精英怪 45 / 副本遭遇 120 / BOSS 400 / 首通奖励 800 / 悬赏 200–600。
**设计目标**：主线一次通关刚好到 26–28 级，终局刷到 30。

### 4.3 装备系统

**8 槽位**：主手 / 副手 / 头 / 胸 / 手 / 腿 / 脚 / 戒指。

**6 品质**（颜色直接复用现有 UI 令牌，零新增色值）：

| 品质 | 词条数 | 颜色令牌 |
|---|---|---|
| 白 普通 | 1 | `COLOR.TEXT_SECONDARY #9CA3AF` |
| 绿 优秀 | 2 | `COLOR.SUCCESS #22C55E` |
| 蓝 稀有 | 3 | `COLOR.PRIMARY #3B82F6` |
| 紫 史诗 | 4 | `COLOR.PASSIVE #A855F7` |
| 橙 传说 | 4 + **唯一特效** | `COLOR.WARNING #F59E0B` |
| 红 秘境 | 4 + 负面 | `COLOR.DANGER #EF4444` |

**5 词条池**：4 个 DPS 词条 + 耐力（耐力每件固定附带，**不占**词条位）。

| 词条 | 每点 | 上限 | 说明 |
|---|---|---|---|
| 暴击 | +3.75% | 30% | 暴击伤害 1.6× |
| 急速 | +2.50% | 20% | 减 CD / 加快普攻 |
| 精通 | +2.50% | 20% | 职业专属加成（见下表） |
| 全能 | +1.25% | 10% | 伤害 +，减伤一半 |
| 耐力 | 每件固定 | — | 1 点 = 10 生命 |

职业精通：

| 职业 | 精通加成 |
|---|---|
| 战士 | 怒气获取 +，旋风斩伤害 + |
| 法师 | 法术伤害 + |
| 游侠 | 远程伤害 + |
| 牧师 | 治疗量 + |

**词条点预算**：`8 槽 × 4 = 32 点`，随 ilvl 线性解锁（ilvl10 可分配 8 点，ilvl40 满 32 点）。
均衡 8/8/8/8 在 ilvl40 **恰好触顶、零浪费**（已验证）。

> **重要澄清（避免走弯路）**：固定预算 + 线性词条 ⇒ **均衡配点永远最优**，这是数学事实。
> 所以副属性不承担「构筑深度」，它是**地板**。深度只能来自三处：
> 1. **急速断点**：CD 8s 的技能在急速 6.7% / 20% 时，60 秒内分别多打 1、2 次 → 存在真实阈值。
> 2. **天赋**：把某个副属性的收益放大（如「暴击时额外治疗」让暴击对牧师更值钱）。
> 3. **饰品 + 改造词条**：直接改规则（见 §7）。

**改造词条（本方案的关键，30% 掉落带）**——不写数值，写行为：

```
「余烬」：火球术变体 A 的持续伤害可以叠 3 层
「回响」：每第 3 次施放同一技能，冷却减半
「裂魂」：暴击时有 20% 概率重置闪避冷却
「荆棘」：受到近战伤害时反弹 30%，但最大生命 −10%
「贪食」：拾取掉落时 5% 概率额外掉一件（品质不高于当前）
```

> **这是不缩水的分界线**。纯数值装备只是时间问题，改造词条才让玩家「为了一件装备改打法」。
> 50 件基型里约 15 件带改造词条，全部手工命名 + 手工写效果，不随机生成。

**装备获取**：
- 副本 BOSS 首通：固定紫装（每个副本一件，对应职业主手/副手）
- 副本 BOSS 重复刷：紫/橙随机词条 roll
- 野外宝箱：白/绿/蓝
- 悬赏：指定部位
- 铁匠铺：**重铸**（花材料重 roll 一条词条）/ **附魔**（把一条词条转移到另一件）

### 4.4 天赋树

**模型（对齐 WoW 小天赋，制造真正的取舍）**：

- 每职业 **3 条线 × 5 层 × 2 选 1 = 30 个天赋**，同层两个互斥。
- 每个天赋可投入 **1–5 点**（1 点 = 1 天赋点），效果按点数线性放大。
- 每线最多 **25 点**（5 层 × 5）；30 级共 **30 点**。
- 层 N 解锁需**该线已投入 5×(N−1) 点**。

于是三种典型点法都成立：

| 点法 | 分配 | 结果 |
|---|---|---|
| 深度 | 一线 25 + 另一线 5 | 一条线满，职业定位极端 |
| 广度 | 两线各 15 | 两条线中段，适应性强 |
| 混搭 | 三线各 10 | 三线低层，靠低层天赋堆基础 |

**单机适配**：原稿的「统帅（团队增益）」线在单机没有队友，改为 **战术（控场 + 资源）**。

数据结构（扩展 `ThunderCore` 骨架）：

```typescript
export interface TalentDef {
    id: string;
    tree: 'steel' | 'fury' | 'tactic';   // 以战士为例
    tier: 1 | 2 | 3 | 4 | 5;
    col: 0 | 1;                          // 同层二选一
    name: string;
    desc: string;                        // 单点效果
    maxRank: number;                     // 固定 5
}
```

**重置代价**：营地训练场，花 200 金 + 材料，无次数限制（单机不该惩罚实验）。
120 个天赋的完整内容见 **§14.1**。

### 4.5 技能升级

- 技能书来源：副本掉落 / 悬赏。
- 每个技能 5 级，升到 2/4 级时弹出**变体二选一**面板。
- 变体选择**永久**（每技能一次），存档记录。营地可花高价「洗点」（500 金）。

### 4.6 营地设施（永久养成，5 条）

| 设施 | 功能 | 1–5 级效果 |
|---|---|---|
| 铁匠铺 | 重铸 / 附魔 / 分解 | 解锁附魔 → 重铸可锁 1 条 → 锁 2 条 → 免费洗 1 次/副本 |
| 附魔台 | 词条转移 | 转移 1 条 → 转移 2 条 → 保留原装备 → 品质降级保留 |
| 训练场 | 重置天赋 / 洗技能 | 解锁 → 半价 → 免费 → 保存两套天赋方案 |
| 厨房 | 消耗品（进本前吃 buff） | 3 种 → 5 种 → 双 buff → 团队 buff → 持续 3 副本 |
| 军需官 | 悬赏板 + 仓库 | 3 悬赏 → 6 → 每日刷新 → 装备仓库扩容 → 材料仓库 |

设施升级用**材料**（副本/野外掉落），不用金币——金币留给重铸，形成两条经济线。

## 5. 野外（节点路线图）

### 5.1 结构

**3 个区域 × 每区 12 节点**，一张图一次远征（进入后节点消耗不可逆）。

```
起点 ── 战斗 ── 精英 ──┬── 宝箱 ── 副本入口
  │                      └── 篝火 ─── BOSS 节点
  └── 事件 ── 战斗 ── 精英 ── 宝箱
```

节点类型：

| 节点 | 内容 | 产出 |
|---|---|---|
| 战斗 | 3–5 波小怪 | 经验 / 材料 |
| 精英 | 1 精英 + 2 小怪 | 蓝绿装概率 |
| 宝箱 | 解谜/代价选择（掉血换装备） | 装备 |
| 事件 | 3 选 1 文本选项（轻叙事） | 材料 / buff / 稀有 |
| 篝火 | 回血 `min(40% 上限, 缺失生命)`（一次性，**不补补给**）+ 进度存档点 | — |
| 副本入口 | 进入该副本 | — |
| BOSS 节点 | 区域首领 | 橙装概率 |

### 5.2 风险

- **补给值**：每次远征带 3 点补给，每个节点消耗 1 点。补给耗尽后每节点扣 8% 最大生命。
- **移动规则（M4 实现口径）**：点起点随时免费回退；与当前位置直接相连的**已清理**节点可免费路过（奖励不重复）；
  正停在一个未结算节点上时，点当前节点可免费重开其内容（防止刷新后内容打不开）；
  已清理但不相邻的节点不可进入。
- 死亡：丢失本次获得的**材料**，装备保留，退回区域起点。
- 这个设计让「走哪条路」成为真决策：多贪一个宝箱可能补给不够打 BOSS。

### 5.3 区域梯度

| 区域 | 节点等级 | 对应装等 | 副本 |
|---|---|---|---|
| 灰烬荒原 | 1–10 | 1–12 | 1、2 |
| 霜牙峡谷 | 10–20 | 12–26 | 3、4 |
| 秘银深渊 | 20–30 | 26–40 | 5、6 |

### 5.4 区域首领（3 只，已定：做）

每个区域路线图的终点各有一只**区域首领**，与副本 BOSS 共用「打断 / 转火 / 走位」三套机制解算器，
但编排不同、掉落不同。它负责在**进入副本之前**给玩家一次「毕业装检验」。

| 区域 | 首领 | 三阶段机制 | 掉落 |
|---|---|---|---|
| 灰烬荒原 | 灰烬领主 | 火焰吐息（走位）→ 召唤火元素（转火）→ 裂隙读条（打断） | 蓝装必掉 + 15% 橙 |
| 霜牙峡谷 | 霜牙狼王 | 扑击（闪避节奏）→ 召唤狼群（转火）→ 嚎叫读条（打断） | 紫装必掉 + 20% 橙 |
| 秘银深渊 | 深渊守望者 | 触手横扫（走位）→ 召唤暗影仆从（转火）→ 深渊低语读条（打断） | 紫装必掉 + 30% 橙 |

**为什么值得做**：它把「野外」和「副本」接起来——玩家刷完一张图不是白刷，而是有终局奖励；
同时复用了 3 套机制解算器，**代码成本只有 3 份编排表**（约 120 行配置）。

## 6. 副本（6 个，手工固定）

每个副本 = **3 个遭遇 + 1 个 BOSS**，共 6 × (3 + 1) = 24 个战斗场景。

| # | 副本 | 装等 | BOSS | 三阶段机制 |
|---|---|---|---|---|
| 1 | 废弃矿坑 | 1–10 | 矿坑巨魔 | 砸地 AoE → 召唤矿工（转火）→ 狂暴读条（打断） |
| 2 | 腐化教堂 | 10–16 | 堕落主教 | 治疗图腾（转火）→ 追踪圣光（走位）→ 群体忏悔（打断） |
| 3 | 冰封哨塔 | 16–22 | 霜巨人 | 冰面减速（走位）→ 冰柱落点（躲避）→ 全屏冰冻（击碎冰柱解除） |
| 4 | 熔火熔炉 | 22–28 | 熔炉守卫 | 火墙推进（走位）→ 熔岩涌泉（躲避）→ 过载读条（打断） |
| 5 | 暗影回廊 | 28–34 | 影刃刺客 | 分身（识别真身）→ 背刺（朝向）→ 影分身连击（闪避节奏） |
| 6 | 秘银王座 | 34–40 | 秘银君王 | 三系法术轮换（打断顺序）→ 王座震击（走位）→ 最终狂暴（DPS 检验） |

**机制模板只有 3 类**（打断 / 转火 / 走位），通过**排列组合 + 节奏变化**产生 6 个不同 BOSS。
这是「内容量不是成本」的关键：6 个 BOSS 复用 3 套机制的解算器，手工的是**编排**不是**代码**。
