## 3. 本轮新发现

### N19（P1，建议优先）雷霆战机：「退出本关」= 免费刷 30 金币 + 文案说谎

**复现（3 次，全部真实点击）**：

1. 关卡列表点第 1 关 → 开局；
2. 立刻点右上「II」暂停 → 点「退出本关」；
3. 结算面板出现：**「任务失败 / 在「侦察编队」被击落 / 得分 0 / 本局金币 +30」**；
4. 点「返回关卡」→ 再进第 1 关 → 再退出，金币继续 +30。

实测金币轨迹：`105 → 135 → 165 → 195`，**全程没有开一枪**。首次升级 100 金，等于「进关-暂停-退出」×4 就够，
比真的打一局快得多，养成线被绕过。

**代码原因**（`assets/games/game_thunder/scripts/ThunderGame.ts:704-710 / 788-791 / 827`）：

- `_quitBattle()` 直接 `w.phase = 'lost'` 然后 `_finish(false)`；
- `_finish()` 里失败保底 `consolation = won ? 0 : Math.max(0, 30 - w.coinsEarned)`（第 790 行），
  不区分「被打死」与「主动退出」；
- 结算文案写死 `在「${w.wave.name}」被击落`（第 827 行）。

**建议**：`_quitBattle()` 走单独的「主动退出」分支 —— 不给保底金币（或给 0）、结算标题用
「已退出本关」而不是「任务失败/被击落」；若想保留保底，加条件 `w.lives <= 0 && !quitByPlayer`。

### N20（P2，遗留确认）推箱子 / 泡泡龙：点锁定关卡完全没反馈

- **泡泡龙**（本轮实测）：点标题打开「选择关卡」→ 点灰掉的第 10 关 → 无 toast、无震动、面板原样留着。
  代码：`BubbleGame.ts:773` `onTap: unlocked ? () => this._onPickLevel(id) : () => undefined`。
- **推箱子**：同款行为（第四轮记录，本轮复看仍如此；`maxLevel=2`，第 3–20 关灰显，点了没反应）。

**建议**：锁定关卡点击给一句 toast（如「通关第 N 关解锁」）或轻微抖动，至少让玩家知道「点了，只是不能进」。

### N21（P3）放置小店：离线收益遮罩 alpha 215，与全站 235 不一致

`IdleGame.ts:497` 用 `dim.fillColor = toColor(UI.overlay, 215)`（84%），
而本轮刚统一的四款结算是 235（≈92%）。截图里底层「点我赚钱」按钮仍能读出来，
观感上像「还能点」。建议随全站遮罩令牌一起收敛到 235。

### N22（P3）纸牌接龙通关面板：只有「再来一局」，左上返回键被压暗

通关后 `WinPanel`（`Canvas/Board` sibling 6）盖住 `TopBar`（sibling 4），`Bg` alpha 200。
`Bg` 未监听触摸，**实测点左上返回键 (52,1252) 能正常回 Lobby**，不是锁死；但按键被压暗、面板也没有
「返回大厅」按钮，和本轮刚修的另外四款不一致。建议补一枚「返回大厅」按钮（复用现成三键布局）。

### N23（P3，代码卫生）雷霆战机「生命 ×N」标签脱离战斗后仍常驻

`_showBattleChrome()` / `_hideBattleChrome()` 管理了炸弹键、暂停键、关卡名、分数，
**漏了 `_livesLabel`**。实测关卡列表页读到的 active 标签里仍有「生命 ×0」，且每打一局数值会更新（×3）。
目前它被关卡卡片 / 结算遮罩盖住，肉眼看不到，属于潜在事故（一旦调层级就会露出来）。
建议把 `_livesLabel.node.active` 一起纳入这两个方法。

### N24（P3，一致性）雷霆战机结算遮罩 alpha 232

与全站 235 差 3，肉眼几乎不可辨，登记在这里只为后续收敛时一把改掉。

## 5. 方法与数据说明

- **探针坑（留给下一轮）**：Label 的世界坐标必须先减去 `Canvas` 的 `UITransform` 世界原点再换算，
  直接 `worldPosition + (360,640)` 会让点击坐标整体偏移 (360,640)、落到画布外（本轮因此空点两次、误判过）。
- **探针坑**：在 `setTimeout` 里读不存在的字段（如把 `_weapons` 当数组 `map`）会让 Promise 永不 resolve，
  MCP evaluate 挂到 120s 超时；脚本里所有读回都加了 try/catch + 空值保护。
- **探针坑**：`cc.director.loadScene()` 切换瞬间 `getScene()` 可能为 null，遍历前必须判空。
- **测试数据污染**（都在 localStorage，未提交）：
  `tiny_games_thunder_*`（金币 195、机炮 Lv.2、第 1 关最高分 1234）、
  `tiny_games_solitaire_stats`（played 1 / won 2，系本轮直接调 `_onWin()` 两次的探针副作用，非真实流程）、
  `tiny_games_fridge_*`（最佳层数/图鉴）、`tiny_games_idle_*`（3h 离线档）、
  `tiny_games_bubble_*`（maxLevel=2）、`tiny_games_sokoban_*`（maxLevel=2）、
  `tiny_games_wordle`（今日已猜中）。
  如需还原干净状态，清对应键 + 整页 reload 即可（注意活着的场景实例会把旧值写回，只清 storage 不 reload 会得出错误结论）。
- 本轮**没有修改任何 `.ts` / 场景 / 预制体**，仓库工作区仍是开发方那 7 个改动文件。
