## 2. 交付内容

### 2.1 纯逻辑（无 cc 依赖，可 node 自检）

| 文件 | 内容 |
|---|---|
| `MithrilWild.ts` | `buildWildMap(seed)` 分层图生成（层数 / 列数 / 连线 / 节点类型 / 等级）、`createExpedition`、`enterNode` 全部走法规则、`isAdjacent`、补给与耗尽扣血、宝箱（陷阱 25% 概率、失去 15% 上限生命 + 金币 `30+等级×2`）、事件三选一、篝火回血 40%、击杀 / 通关 / 死亡 / 放弃的结算 |
| `MithrilConfig.ts` | 三区域（灰烬荒原 / 霜牙峡谷 / 秘银深渊）等级段与敌人池、`SUPPLY_PER_RUN=3`、`SUPPLY_EXHAUST_HP_PCT=0.08`、`NODE_KIND_NAMES`（含篝火） |

**走法规则（N39 修复后的完整口径）**

1. 点「起点」：随时免费回起点，不扣补给、不扣血（`start`）。
2. 点当前所在、尚未结算的节点：免费重开内容（`resume`，防「刷新后内容打不开」的软锁）。
3. 点与当前位置**直接相连**的已清理节点：免费路过，位置改变、奖励不重复（`transit`）。
4. 点新节点：扣 1 补给；补给为 0 则扣 `round(maxHp×8%)` 生命，生命归零即倒在路上。
5. 点已清理但**不相邻**的节点：`done`，提示不重复进入。
6. 点不相连、未清理的节点：`not_reachable`。

### 2.2 游戏层

| 文件 | 内容 |

| `MithrilWildMap.ts` | 720×1280 地图面板：顶栏读数（生命 / 补给 / 本区域材料）、补给耗尽橙色警告行、区域页签（`·已通关` / `LvN` 未解锁）、分层节点与连线（绿线可达、蓝圈可路过、白圈当前位置、红圈当前可打 BOSS）、图例两行、宝箱 / 事件 / 篝火 / 消息弹窗 |
| `MithrilHud.ts` | 战斗中首领血条与玩家生命取整显示（N40） |

### 2.3 数值口径

- 补给：每程 3 点；新节点 1 点；耗尽后每新节点 `round(maxHp×8%)` 生命。
- 篝火：回 `min(40% maxHp, 缺失生命)`，一次性，**不补补给**。
- 宝箱：金币 `30 + 等级×2`；25% 概率陷阱，失去 15% 上限生命。
- 事件：三选一（材料 +2 / 回 25% 生命 / 材料 +3 但失去 10% 生命）。
- 通关：击杀区域首领 → 该区域写入 `regionsCleared`，本程材料入总库存。

## 4. 复现命令

```bash
TSC="/Applications/Cocos/Creator/3.8.8/CocosCreator.app/Contents/Resources/app.asar.unpacked/node_modules/typescript/bin/tsc"
node "$TSC" --noEmit && echo TS_OK
node tools/verify-mithril-wild.js      # 2828 项
node tools/verify-mithril-core.js      # 202/202
```

预览复验：`http://127.0.0.1:7456/` → 大厅进「秘银远征」→ 野外地图。
改过 `.ts` 后顺序固定：tsc → MCP `project_refresh_assets` → 整页重载（否则跑的是旧代码）。

**存档恢复注意**：游戏在页面卸载时会再写一次存档，所以「先 `localStorage.setItem` 再 reload」会被旧内存状态覆盖。要回到某个存档快照，应当 `comp._save = <对象>; comp._persist();` 之后再 reload。

**本轮预览复验的环境坑（已写入 `docs/tech/browser-verify-cocos-preview.md` §4.5）**：本机预览的 canvas 绘制缓冲是 `393×679`，而元素 CSS 尺寸是 `393×846`，**渲染位置与命中位置不一致**；按老公式（fit + `(1 - sp.y/canvas.height)`）算出的坐标会点不中。本轮实测可用的换算是
`cssY = window.innerHeight - sp.y`、`cssX = rect.left + sp.x`（`sp = camera.worldToScreen(worldPos)`），
并用 `e.getUILocation()` 反查引擎认为点到了设计坐标的哪里来确认。
