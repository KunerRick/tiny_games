**手感与节奏**：矿坑巨魔 3000 血在 Lv7–8 用「贴身外圈绕走 + 普攻自动索敌」打了 2:29、剩 104/168 血，紧张但不折磨，属于可接受的首通强度（前一晚的失败是我的自动脚本站进了接触范围，不是数值问题）。升级瞬间只补上限差额、不回满血，让「继续推还是回城」有取舍，符合设计意图。

**主要短板**：N36。技能/变体是 M3 的核心付费点（书、500 金重置），但玩家在界面上看到的仍是 Lv1 的基础数字，选完变体也不变，只能靠下方小字自行推断，容易怀疑「我选的变体是不是没生效」。

## 方法与数据说明

- 环境：Cocos Creator 3.8.8 编辑器预览 `http://127.0.0.1:7456/`（编辑器由用户预先启动，未自行拉起）；Playwright 浏览器视口 **414×896 CSS**，`devicePixelRatio = 1`。
- 坐标标定（现场反解，未沿用旧值）：canvas `getBoundingClientRect() = {x:10.5, y:49.71875, w:393, h:846.28125}`；等比铺满下 `s = 393 / 720 = 0.5458333`，可视世界高度 `846.28 / s = 1550.4`，顶部世界 y `= 640 + 774.96 = 1414.9583`。换算：`clientX = 10.5 + worldX × s`，`clientY = 49.72 + (1414.9583 − worldY) × s`。所有点击用 `page.mouse.click(clientX, clientY)` 派发真实指针事件，**不是**把 CSS 坐标当设备像素传（本轮 `k = 0.5458`，既不等于 1 也不等于 dpr）。
- 操作路径：全部走游戏自身输入 —— 键盘 `WASD` 移动、`J` 普攻、`K/L/U/I/H` 技能、`T` 成长面板；界面操作全部是鼠标点真实按钮（结算「成长 / 装备 / 再来一次 / 返回大厅」、天赋格、技能「升级 1 本」、变体槽、「穿上」、洗点/重置）。
- 页面重载：开始整页 reload 一次；持久化验证时关面板后等 1.2 s 再整页 reload 一次。
- 页内探针（只读）：`g._save`、`g._core.time/phase/player/profile/skills`、`g._growthRef.isOpen()`、HUD 节点树与 Label 文本；用 `window.__toCss` 与运行时 rect 反解坐标。
- **未改任何状态**：没有写过 `localStorage`/存档，没有直接改金币、经验、血量、道具、天赋、技能或变体；报告里出现的所有进度变化都由真实按键与点击产生。
- 一个环境现象（不计缺陷）：整页刷新后 `document.activeElement` 是 `BODY`，键盘事件无人接收；在画布上点一下变为 `CANVAS` 后一切正常。真人在桌面端点一下就会恢复，移动端本来就是触摸。

## 未复现 / 已排除的疑点

1. **「矿坑巨魔 3000 血打不死」——排除**。切线走位（与 BOSS 保持 92–118 px）+ 普攻自动索敌，Lv7–8 用 168 血在 2:29 击杀；此前几轮失败是自动脚本站进接触伤害范围（≈58 px）导致，不是数值或机制缺陷。
2. **「击杀回 1% 生命」像是 HUD 弹了提示——排除**。该文本来自未激活的狂怒系天赋格，被递归遍历 Label 时读到，不是战斗提示。
3. **胜利后顶栏残留 BOSS 血条「1/3000」「打断失败」「狂暴中」——排除**。只在成长面板打开（游戏暂停）时读到；关闭面板后 HUD 立刻刷新、这些标签全部消失，且当时被全屏遮罩挡住，玩家看不到。
4. **刷新后键盘/技能无响应——排除**。见「方法与数据说明」最后一条，是画布焦点问题，点一下即恢复。
5. **局内改变体是否即时生效——未验证**。收尾时书已用尽、两个 2 级变体也已选满，无法在存活局内再改；最后一次改「铁肩」是在死亡结算界面，只能证明「结算后改变体只写入存档、不改本局 profile」。**已确认**的是下一局 `profile.skills` 会正确携带等级与变体。技能页也没写生效时机（天赋写「立刻作用于当前这一局」、装备写「下一局生效」），建议补一句。
6. **结算经验与首通 +800 的跨级换算——未独立核对**。缺「进本前」的存档快照；本轮只验证了可核对的部分（651 + 177 = 828 → 升 Lv9、exp 归 0）。
7. **技能升级数值变化极小（+0.5% 伤害 / −1% 冷却）**——不是 bug，详情页脚已写「升级只加少许伤害 / 冷却，真正质变在变体」；问题只是它没把这些「少许」显示出来（并入 N36）。

## 复现配方

前置：预览服务在跑；整页 reload 后先在画布空白处点一下（`clientX≈338, clientY≈222`）取得键盘焦点；坐标按上面的公式现算。

**N36（技能文案不随等级/变体更新）**

1. 任意结算页点「成长」（或按 `T`）→ 点「技能」（世界 448,1000）。
2. 在「劈砍」行点「升级 1 本」（世界 305,876）：书 2→1，出现「2级·横扫 / 2级·迅斩」。
3. 点「2级·横扫」（世界 426,894）：变为「已选·横扫」，存档 `variants.warrior_basic = [0,null]`。
4. 观察：行文案与底部详情仍是「90° 扇形，110% 攻击」，Lv1→Lv2 数字逐字未变。
5. 关闭面板 → 点「再来一次」→ 探针读 `_core.profile.skills.basic`：`{level:2, dmgMul:0.9045, cdMul:0.99, v2:{arcMul:1.3333, dmgMul:0.9}}`（即 120°、伤害 ×0.9），与文案矛盾。

3. 探针：`save.level=8`、`profile.level=7`、`player.maxHp=168`；下一局开局 `maxHp=246`（含装备）。

**N38（首通技能书两行文案）**

2. 读结算面板：「首通奖励：经验 +800　技能书 +1」与「技能书 +2 本（现有 2）」。
