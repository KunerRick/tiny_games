> 上一轮报告：`docs/plans/2026-11-17-playtest-round23-mithril-deep.md`（只当待验证清单；N66–N74 的数值/流程结论本轮不重提）
> 本轮范围：**各界面的 UI 元素完善度**，重点验证玩家两条反馈（① 营地面板全是文字 ② 受击反馈过大、满屏红）

## 1. 结论

**两条玩家反馈都复现。**

1. **「大厅/营地是空的，铁匠铺啥的都是文字」——成立，但范围要修正。**
   - 「空」的不是大厅：大厅 24 张卡片各有专属 Graphics 图标与浅色底（`r24-10`）；野外地图的节点也都有图形（剑/星/箱/十字/骷髅/篝火/矿镐）。
   - 真正「纯文字」的是**游戏内面板**：营地五个设施页（铁匠铺 / 附魔台 / 训练场 / 厨房 / 军需官）、角色-装备、角色-饰品、成长-天赋、成长-技能、职业选择，**整屏只有 Label 与纯色矩形，没有任何设施/装备/天赋/技能图标**，多处中下部有 300+ 设计像素的空白区（`r24-02`…`r24-09`、`r24-29`、`r24-30`）。观感确如玩家所说「像半成品」。
2. **「战斗界面被击反馈太大，整个屏幕都红」——成立。**
   - 每一次**对玩家的伤害**（包括 2 点小伤害）都会把 `_hurtFlash` 拉到 **0.8**（红层峰值 `alpha≈72/255`，覆盖整个战场矩形），持续约 **0.2 s**；同时 `_shake` 固定 **0.35**（位移约 2.5 设计像素）。
   - **强度与伤害量、与剩余血量完全无关**：58/60、56/60（满血附近）与 2/96（濒死）三张截图里的红闪肉眼一致（`r24-35-fullhp-hit-0/1`、`r24-14-burst-2/3`）。
   - 范围修正：红闪只铺在**战场矩形**内，顶部 HUD 与右下技能按钮不被染色——应描述为「整个战场泛红」，而不是「连 UI 都红」。

**计数：P0 0 ｜ P1 1 ｜ P2 8 ｜ P3 3（共 12 条，编号 N75–N86）。**

主流程无卡死、无白屏；全程浏览器控制台 **0 error / 2 warning**。本轮没有 P0。

**未到达的界面**：事件/宝箱/篝火结算、地牢确认卡、BOSS、战斗胜利结算（原因见 §5）。

## 4. 方法与数据说明

- **环境**：macOS，Cocos Creator 3.8.8 编辑器预览，`http://127.0.0.1:7456/`；Playwright MCP 浏览器，视口 **1280×720**，预览设备 iPhone 14 Pro（设计分辨率 720×1280）。
- **坐标标定（现场）**：Canvas 矩形 `left≈443.5, top≈41, width≈393, height≈679`，反解为
  `clientX = 443.5 + uiX × (393/720)`、`clientY = 720 − uiY × (679/1280)`。
  用 `TOUCH_START` 读 `getUILocation()` 回验：在 CSS (639, 64) 点击读回 **(359.12, 1236.64)**，与公式一致。
  **本轮 `page.mouse` 传 CSS 像素即可（k=1）**；每次点击前重新读节点世界坐标换算，未沿用上一轮数值。
- **状态改动：清档 1 次。** 用 `page.addInitScript` 一次性 `localStorage.removeItem('tiny_games_mithril_save')` + `sessionStorage.__r24_wiped` 守卫 + 整页 reload；之后所有进度（新档、Lv1→Lv4、金币、天赋点、装备空态）均由游戏自身输入获得。
- **未使用任何跳过手段**：未调用 `debugKillAll()` / `debugGotoBoss()` / `debugSetPlayerPos()`，未改金币/血量/装备/材料/存档字段。战斗只通过键盘（WASD/方向键移动、J 普攻、K/Space、L、U、I、H）与点击技能按钮推进。
- **探针**：`cc.director.getScene()` 取 `MithrilGame` 组件 → `core.phase` / `core.player.hp` / `core.enemies`；包装渲染器 `rend.onEvents` 记录 `damage` 事件；对私有字段 `_hurtFlash` / `_shake` 做 rAF 采样（峰值实测 **0.7368**，配置值 0.8；`_shake` 恒为 0.35）。
- **截图**：全部由 Playwright 截取，1280×720，存放 `.playwright-mcp/`，前缀 `r24-`。中途多次 reload，**编号与内容有 4 处错位**（`r24-01` 实为地图、`r24-25` 实为死亡结算、`r24-26` 实为地图、`r24-27` 实为战斗），§7 按实际内容标注。
- **控制台**：本轮全程 **0 error / 2 warning**（warning 与 UI 无关，未出现红字异常、未出现资源 404）。
- **未改任何 `.ts` / `.scene` / `.prefab`，未提交 git。**

## 5. 未复现 / 已排除的疑点

1. **「大厅是空的」不成立。** 大厅 24 张卡片均有专属图标与浅色底（`r24-10`）；玩家感到的「空」来自游戏内面板（营地/装备/成长），已归入 N75/N77/N79。
2. **「整个屏幕都红」范围需修正。** 红闪只铺在战场矩形内，顶部 HUD、技能按钮、暂停/结算面板都不被染色（`r24-35-fullhp-hit-0` 中技能按钮颜色正常）。因此现象是「整个战场泛红」，不是「连 UI 都红」。
3. **BOSS 受击是否更红：未实测。** 本轮最高 Lv4，BOSS 推荐等级 17，无法到达；代码路径对所有 `target='player'` 的 damage 事件用同一常量，故判断为同强度，但仅有代码佐证，无实机对比。
4. **震屏是否「整个屏幕抖」：否。** 震屏作用于战场渲染节点，HUD 不抖；位移约 2.5 设计像素，肉眼需仔细看才察觉，与红闪的冲击感不成比例。
5. **技能冷却是否只有数字：未逐技能计时验证。** 观察到按钮下方出现 0.8、3 等小数字与变暗效果，但未对 6 个技能逐一计时核对。
6. **装备/饰品/天赋「点击被拒」的提示：未复现。** 本轮天赋点 0、金币 0，无法触发「点数不足/金币不足」分支；无法判断拒绝时是否有 toast 或仅静默。
7. **页签点击无响应 / 状态不同步：未出现。** 营地 5 个页签、装备/饰品、天赋/技能页签切换均正常，选中态跟随。
8. **死亡面板返回按钮：正常。** 点「返回路线图」回到野外地图（`r24-16` 实为死亡后的地图）。
9. **上一轮 N66–N74（BOSS 时长、远程锁定线、首次提示、撤退）**：本轮只做 UI 巡检，不重新判定数值/流程；首次战斗提示的 3 行文案完整可读（`r24-33`）。

## 6. 复现配方

**A. 营地面板纯文字（N75/N76）**
1. 清档或新档进入 → 大厅点「秘银远征」→ 选职业 → 地图。
2. 地图底部点「营地」。
3. 依次点「铁匠铺 / 附魔台 / 训练场 / 厨房 / 军需官」，五页各截一张（`r24-02`…`r24-06`）。
4. 观察：无设施图标、页头无图形、禁用项为灰字、中下部空白。

**B. 受击全屏红（N82/N83/N84）**
