## 1. 复核方法（可复现）

每款游戏走同一条链路：`cc.director.loadScene('<Scene>')` → 截图 → 递归读所有激活 `Label` 的 `string` 与 `worldPosition` → 按设计坐标换算成 CSS 坐标点击/拖拽 → 再读状态对比。

```js
// 设计坐标 → CSS（本机实测）
const css = (x, y) => [25.5 + x * 0.53047, 727 - y * 0.53047];

// 读全部激活文案 + 坐标（判断重叠/位置）
const walk = n => { if (!n.activeInHierarchy) return;
  const l = n.getComponent && n.getComponent('cc.Label');
  if (l && l.string) rows.push([l.string, n.getWorldPosition(), l.fontSize, l.color]);
  n.children.forEach(walk); };
```

> 注意：`Solitaire` 底栏、`TD` 塔位这类节点的 `worldPosition` 不在 0–720/0–1280 设计空间（返回负值），这类位置一律以截图目测为准，不套公式。

## 4. 原报告中需要更正的 4 条

### 4.1 小小先锋「战斗回合无法推进」→ 实为「等待玩家操作」+ 提示不足
上一轮我把「最后一名单位待命」的静止态误判成卡死。实测链路完整可用：绿格走位（两段式确认）→ 敌人进入攻击 → 技能瞄准 → 回合 1→2。修好后的提示已经明确写了「再次点击同一格确认移动」，可以结案。

### 4.2 推箱子「步数 1」→ 实为存档续玩
读 `tiny_games_sokoban_save` 后确认关卡进度与步数都会续存（再次进入显示「步数 2」即我上一轮走的格数），不存在「开局步数从 1 开始」的 off-by-one。

### 4.3 推箱子「无选关入口」→ 入口存在，但不可发现
点「第 2 关 · 拐个弯」这行标题会弹出完整的「选择关卡 1–20」面板（当前关高亮、未解锁灰）。功能没问题，问题是**标题没有任何可点击的视觉提示**，玩家不可能猜到（见 N7）。

### 4.4 贪吃蛇死因 / 小店日记等级点 / 成语猜猜连接线
三点均复核为「设计如此 / 不复现」，与修复计划的 `[—]` 说明一致：贪吃蛇只有撞墙一种死法且文案已写；Idle 设施卡同时有 `Lv 0/5` 文本与 5 个圆点；Wordle 是逐格独立圆角槽。
