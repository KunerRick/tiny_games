## 1. 一句话玩法

拖拽瞄准、松手出杆，把台面上的目标球一颗颗打进袋；杆数用完还没清台就算失败。

## 2. 目标体验

- 合集第一款**体育手感**品类，与现有 17 款零重合。
- 一局 3–8 分钟，三关递进（6 / 10 / 15 颗球），失败立刻重来。
- 手感优先：瞄准线给出幽灵球位置，力度条给出预期的滚动距离，玩家不用赌。
- 物理必须「看起来对」：等质量正碰后母球基本停住、库边反弹角度合理、球不会穿过去。

## 3. 规则

### 3.1 赛台与球

- 赛台 660 × 330（设计分辨率 720 宽的 1/12 留边），球半径 9（直径 ≈ 台宽的 2.7%，比真实球略大，便于手指识别）。
- 球心可行区域 `[r, W-r] × [r, H-r]`，库边按直墙处理，不做袋口豁口几何。
- 6 个袋：四角（捕获半径 23）+ 两条长边中点（捕获半径 19）。球心进入捕获半径即落袋。
  - 角袋沿库边的落袋区间约 ±21 px（≈1.2 个球直径）；中袋约 ±14 px（≈1.5 个球直径）。

### 3.2 摆球

- 目标球三角摆放，顶点在 `(0.72W, 0.5H)`，相邻球心间距 `2r + 0.8`（互不重叠、几乎贴死）。
- 球号 1..N 用种子随机洗牌后填进三角，同一 seed 排布固定（可复现）。
- 母球初始在开球点 `(0.25W, 0.5H)`。

### 3.3 物理参数（`POOL_PHYS`）

| 参数 | 值 | 说明 |
|------|----|------|
| 外层固定步长 | 1/120 s | 帧率无关，核心内部累加推进 |
| 滚动摩擦 | 780 px/s² 线性减速 | 满力 1900 无碰撞可滑行 ≈2314 px（3.5 个台宽） |
| 停止阈值 | 8 px/s | 低于即归零，杜绝无限微动 |
| 球-球恢复系数 | 0.95 | 等质量，正碰后母球保留 2.5% 速度 |
| 库边恢复系数 | 0.86 | 每次撞库明显掉速 |
| 速度上限 | 2000 px/s | 硬保护 |
| 出杆速度 | 300–1900 px/s | 由力度 0..1 线性映射 |
| 自适应子步 | 单步位移 ≤ 0.4·r = 3.6 px | 满速时内层约 5 个子步，**杜绝穿透** |
| 求解迭代 | 3 次 | 位置修正 + 冲量 |

### 3.4 关卡

| # | 名称 | 球数 | 三角行数 | 杆数上限 | 连击加成 |
|---|------|------|----------|----------|----------|
| 1 | 热身三角 | 6 | 3 | 14 | +50% / 颗 |
| 2 | 双层进击 | 10 | 4 | 26 | +60% / 颗 |
| 3 | 满台清空 | 15 | 5 | 40 | +80% / 颗 |

杆数上限约为球数的 2.3–2.7 倍：允许明显失误，但不允许无脑乱打。

### 3.5 计分与胜负

- 每颗目标球基础 100 分；同一杆内第 k 颗球倍率 `1 + (k-1) × 连击加成`。
- 清台时额外奖励 `剩余杆数 × 60`。
- **胜利**：目标球全部落袋。
- **失败**：杆数达到上限仍有球在台上。
- **母球落袋（滑杆）**：不扣分、不计进球，本杆结束后母球复位到开球点；开球点被占则围绕它螺旋搜索最近空位。
- 存档：每关最佳分、是否通关、上次关卡、累计进球。

## 4. 界面布局（设计分辨率 720×1280，左上原点）

```
┌──────────────────────────────┐
│ ‹           台球             │  标题 y=64
│  关卡 2/3   杆数 8/26  分数 640│  HUD y=140
│                              │
│  ┌────────────────────────┐  │
│  │   660×330 赛台          │  │  赛台中心 (360, 600)
│  │   6 袋 / 15 球 / 瞄准线  │  │
│  └────────────────────────┘  │
│     ◀ 力度 ████████░░ ▶       │  力度条 y≈820
│                              │
│   [◀ 上一关]  [重开]  [下一关 ▶] │  底栏 y=900
│      拖拽瞄准，松手出杆         │  提示 y=1000
└──────────────────────────────┘
```

- 瞄准：在赛台上按下并拖拽 → 方向 = 按下点指向当前点（或直接指向球心），松手出杆；拖拽距离映射力度。
- 瞄准线：从母球画到幽灵球位置（与目标球相切前的最后一个可停位置），撞库则画到库边交点。
- 结算浮层：胜负、关卡、进球 / 总数、杆数、得分 +「再玩一次 / 换一关 / 返回大厅」。

## 5. 交互流程

```
进入 → 读档 → 加载上次关卡 → 瞄准阶段（可换关 / 重开）
     → 按下拖拽（实时显示瞄准线 + 幽灵球）→ 松开出杆
     → 球滚动（期间忽略输入）→ 全部停下 → 结算本杆
     → 循环直到清台（胜）或杆数耗尽（负）
     → 结算浮层 → 再玩一次 / 换一关 / 返回大厅
```

- 滚动期间输入只更新"待瞄准"状态，不响应出杆。
- 松手时若力度低于最小阈值（拖拽距离很短），视为取消，不出杆。

## 6. 技术方案

### 6.1 纯逻辑核心（已完成）

- `PoolConfig.ts`：赛台几何、袋口、物理参数、关卡表、计分、配色、存档解析（`parsePoolSave` 坏档回落）。
- `PoolCore.ts`：
  - `startLevel(levelId, seed)`：建球 + 三角摆球（洗牌确定性）。
  - `setAimAngle / aimAt / setPower / shoot`：出杆前输入；`shoot` 校验状态与杆数。
  - `step(dt)`：累加器 + 固定 1/120 外层步长；每步内按最大速度自适应细分子步，单子步位移 ≤ 3.6 px。
  - `predictAim()`：射线求第一颗命中的球（返回幽灵球位置）或库边交点，供视图画瞄准线。
  - 事件队列（`shoot/pot/scratch/stroke_end/won/lost`）由 `drainEvents()` 取走，逻辑层不依赖渲染。
  - 母球复位：开球点被占时围绕它螺旋搜索空位。
- 与 `merge` 的差异：无重力、无休眠机制（有摩擦必然停机）、等质量弹性碰撞、自适应子步替代固定 1/240。

### 6.2 运行时 `PoolGame.ts`（已完成）

- 单 `Graphics` 整盘重绘：库边 → 台面 → 袋口 → 瞄准线 / 幽灵球 / 目标球去向 → 球（实心 / 花色 + 高光）→ 球杆。
- `update(dt)` 直接喂 `PoolCore.step(dt)`（核心内部已是固定步长）。
- 触摸：`TOUCH_START/MOVE/END/CANCEL` 具名 handler，`convertToNodeSpaceAR` 换算赛台坐标；拉杆向量 = 起点 − 当前点。
- 力度条独立节点（`PowerBar`），填充从左侧起算。
- 球杆画在出杆方向的反侧；注意 `aimAngle` 是**台面坐标（y 向下）**，转节点局部坐标时只取反 x、y 取反号。
- 音效：v1 不做（项目当前无音频基建）。

### 6.3 自检 `tools/verify-pool-core.js`（24 项，全绿）

覆盖：关卡配置自洽（球数 = rows(rows+1)/2）、开局球数与编号、摆球不重叠且在台内、三角几何、力度映射、非瞄准阶段拒绝出杆、正碰动量转移、库边反弹、摩擦必然停机、**高速正面对撞 1,000 次不穿透 / 不互换位置**、**1,000 杆随机击球不变量（有限、限速、不越界、无严重重叠）**、落袋计分、一杆多球连击、母球落袋复位、清台判胜与剩余杆奖励、杆数耗尽判负、结束后拒绝出杆、瞄准预测三种情形、同 seed 确定性、不同 seed 排布不同、存档往返与坏档回落、关卡越界回落。

```bash
node tools/verify-pool-core.js
```

## 9. 浏览器实测记录（2026-11-07）

预览 `http://127.0.0.1:7456/`，真实鼠标拖拽驱动（按下→多段移动→松开）：

| 场景 | 结果 |
|------|------|
| 开球拉杆 | 拖 200 CSS 像素 → `aimPower=1`、松开后 `rolling`、杆数 +1；球散开且全部留在台内 |
| 进球 | 母球对准球堆右下方的球，力度 0.69 出杆 → 目标球入角袋、`score=100`、HUD 同步「杆数 3/14 · 分数 100」 |
| 瞄准显示 | 拖拽中虚线瞄准线指向预测碰撞点、幽灵球可见、球杆出现在出杆方向的反侧、力度条从左向右填充（>0.75 转红） |
| 母球落袋 | 母球送入角袋 → 本杆结束复位到开球点 (165,165)，不计分 |
| 换关 | ◀换关 / 换关▶ 在 1→2→3→2 间切换，球数 6/10/15、杆数 14/26/40 与关卡表一致 |
| 胜利 | 清空 6 球 → 「清台成功！」，6/6 颗、杆数 1/14、得分含连击加成 |
| 失败 | 把杆数拉到上限前 1 再出杆 → 「杆数用尽」 |
| 大厅往返 | 返回大厅 → 台球卡片出现在「全部游戏」第 18 张 → 点进去回到上次关卡（`lastLevel` 存档生效） |

实测中修掉两个渲染缺陷：球杆方向的 y 轴符号取反（杆画到了出杆方向一侧）、力度条填充居中而非从左起。控制台 0 error。
